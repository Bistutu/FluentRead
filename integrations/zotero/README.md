# FluentRead for Zotero

流畅阅读的独立 Zotero 桌面插件。可从文献库选择 PDF 批量翻译，在 Zotero 阅读器中翻译选中文字，并把译文 PDF 或双语笔记保存回文献库。翻译在本地提取的文字上进行，原始附件保留。

## 构建与安装

在 FluentRead 仓库根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm test:zotero
pnpm build:zotero
pnpm verify:zotero
```

产物为 `integrations/zotero/dist/fluentread-zotero.xpi`。在 Zotero 桌面版中打开“工具 → 插件”，通过齿轮菜单选择“从文件安装插件”，选择该 XPI。兼容清单以 Zotero 7–10 为目标，Zotero 7 的兼容性尚未单独实测。此安装包是独立的 Zotero 插件；无需安装流畅阅读浏览器扩展，也不会读取浏览器扩展的密钥或设置。

这是实验性集成，尚未上架 Zotero 插件目录。已在 macOS 的 Zotero 10.0.6 独立 profile 与资料库中完成真实安装、受控服务全文翻译、中文 PDF 导出回存、双语笔记、幂等重试和停用后重新启用的验收。微软翻译另用一个固定公开句子验证了真实中文响应。整篇论文的真实服务语义质量、Zotero 7–9 及 Windows/Linux 尚未完成实测；建议先在测试资料库使用。

当前为本地测试包，尚未发布到自动更新渠道。清单包含 Zotero 要求的 HTTPS 更新地址；仓库中的 `updates.json` 目前为空清单，需源码合入后才可从该地址读取。构建不会发布插件或推送更新。

## 使用

在流畅阅读工作台配置源语言、目标语言和翻译服务。默认自动识别原文，翻译为简体中文。可以使用内置微软翻译，或配置 OpenAI 兼容服务的 HTTPS 接口、模型和 API Key；本机模型也可填写回环 HTTP 地址。自定义服务需返回 Chat Completions 格式。可填写当前集成独立使用的术语要求，并选择双语或仅译文 PDF。

在文献库中选择带本地 PDF 的文献或 PDF 附件，从流畅阅读菜单加入翻译队列。多个文件依次处理，任务记录保留进度；暂停后可以继续，失败后可以重试。关闭或停用插件后，未完成任务恢复为暂停，由用户继续。已完成片段会复用，继续前检查附件身份和内容摘要，避免把旧译文填入已修改的 PDF。

译文以新 PDF 附件保存到原文献下；独立 PDF 的结果保留在对应文献库和分类中。同一任务再次写回会复用该任务的结果。完成后可以打开译文，也可以从任务操作保存按页排列的原文与译文笔记。清理任务记录不会删除已生成的附件或笔记。

阅读器的选区入口可翻译选中文字。划词与文档任务共用该插件当前的翻译服务和语言配置；笔记保存属于用户明确触发的操作。

## 范围与隐私

- 当前面向 Zotero 桌面版和带文字层的 PDF。扫描 PDF 需要先添加 OCR 文字层；没有内置扫描件 OCR。并非所有加密、损坏或特殊排版 PDF 都能提取文字。
- PDF 解析、排版和结果生成在本地完成。启动翻译时，待译文字和必要的翻译提示发送到选定服务，术语按你的词表处理。不会把整份 PDF 上传到 FluentRead 云端。使用本机服务时，文本发送到配置的本机接口。
- 源语言、目标语言、服务和术语等保存在当前 Zotero 配置目录的 `fluentread/settings.json`，API Key 单独保存在 `credentials.json`，任务进度和译文在 `tasks.json`。密钥不会写入任务快照或生成的笔记，凭据文件是本地文件而非加密密钥库。
- 不收集遥测。首次导出可能按需下载约 5 MB 的固定版本开放字体，经长度与 SHA-256 校验后缓存在当前 Zotero 配置目录的 `fluentread/fonts/`；此请求不包含文献内容或密钥。PDF.js worker、CMap 和标准字体随 XPI 提供，不从 CDN 加载执行代码。
- 当前不提供 EPUB、Zotero 网页版/手机端适配，或原 PDF 批注坐标向译文 PDF 的同步。译文排版与页数可能不同，原有批注继续关联原 PDF。
- 只读文献库会阻止结果回存；找不到本地附件时会提示先下载或重新定位。取消后不会再提交尚未完成的翻译结果，已经保存的独立附件仍保留。

## 结构与授权

`native.ts` 绑定 Zotero 生命周期、菜单和阅读器事件；`platform.ts` 适配文件、文献和笔记；`workspace.ts` 提供 Vue 工作台；`queue.ts` 管理持久任务；`engine.ts` 复用 FluentRead 的文档解析、翻译与导出能力。`package.mjs` 将两份 IIFE、独立 PDF.js worker 及授权文件组成 XPI。

此集成按 FluentRead 的 GPL-3.0 独立实现。沉浸式翻译的 Zotero 插件仅用于理解“选文献 → 翻译 → 结果关联原文献”的用户流程，没有复制其源码，也不依赖其私有 API 或会员授权。XPI 内包含第三方依赖的授权说明。
