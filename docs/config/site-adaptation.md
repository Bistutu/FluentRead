# 网站阅读范围

网页有漏译或翻译范围不合适时，可以调整正文识别范围和网站规则。

GitHub 发布说明会按原文的显式换行逐段显示译文，方便上下对照；包含多个段落的列表项也会分别翻译。

Discord 的服务器图标栏在“正文”和“识别全部节点”范围内都保持原样；频道消息正文仍可翻译。

在默认正文范围内，Hacker News 翻译新闻标题、帖子正文和评论段落，保留用户名、域名、评分、时间及回复、折叠等操作。多段评论分别显示译文，代码保持原样。

Product Hunt 首页逐卡翻译产品介绍，保留产品名称、分类、投票、搜索控件和 Cookie 提示。产品详情页继续使用讨论正文识别；网站要求登录或人机验证时，需要先正常打开正文。

## 正文漏译

1. 安装或更新后先刷新网页。
2. 默认只翻译阅读位置附近的内容，向下滚动看看后续段落。
3. 想补充翻译菜单或导航，在 **高级选项 → 页面识别** 开启 **识别全部节点**，恢复原文后重新翻译。
4. 文字在图片或图表里无法选中时，用[圈选翻译](/guide/area-translation)。

浏览器扩展在 OMG! Ubuntu 文章中会随全文翻译处理 Disqus 评论，在 Kaggle Notebook 中会处理 Markdown 教程正文；滚动到后续内容时会继续翻译。

## 每次都翻译，或始终保持原样

在 **系统与数据 → 网站规则 → 网站偏好** 中按网站调整始终翻译、禁用扩展或隐藏悬浮球。三个偏好集中在同一行，网站输入会归并到主域名并覆盖子域，路径和端口不会进入偏好。

禁用扩展优先于自动翻译，但不会删除该网站的其他偏好；重新启用时会恢复。隐藏悬浮球只影响入口，不关闭快捷键和其他功能。开启“所有网站自动翻译”时，未禁用的网站都会自动翻译，已设置的名单仍保留。移除网站偏好会恢复全局默认，可撤销移除。

“正文适配”用于按域名、路径和 CSS 选择器调整翻译范围；“生效预览”只检查已保存规则的匹配与优先级，不打开网站，也不保证实际网页可翻译。保存后请在真实页面确认效果。

## 仍然识别不对

可以到 [GitHub Issues](https://github.com/FluentRead/FluentRead/issues) 提供网址、浏览器版本和经过隐私处理的截图。说明你希望翻译哪个区域、哪个区域保持原文，通常比描述页面结构更有帮助。

熟悉网页结构的用户可以使用[自定义网站适配教程](/guide/custom-site-rules)。这不是日常使用的必需步骤，修改前建议先导出规则备份。

完整字段说明与规则维护资料保存在[仓库参考文档](https://github.com/FluentRead/FluentRead/blob/main/docs/maintainers/product-reference/site-adaptation-20260906.md)。
