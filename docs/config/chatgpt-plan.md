# ChatGPT 套餐接入状态

**FluentRead 当前公开版本暂时隐藏 ChatGPT 登录接入模块。** 服务目录和详情页不展示此入口；公开接入所需的 OpenAI 申请与批准尚未完成。

请继续在 **设置 → 翻译服务** 中选择当前可用的服务。已有服务设置和完成的译文继续保留；如果之前保存过 ChatGPT 套餐服务或模型，请先为需要使用的功能选择可用服务，原有配置无需删除。

后续开放时，会提供从扩展发起官方授权并自动返回的完整用户流程。可用账户、模型和套餐额度以 OpenAI 的实际权限为准；拥有 ChatGPT Plus 或 Pro 并不代表此功能已经在 FluentRead 开放。

接入状态与套餐使用的官方说明见 [Sign in with ChatGPT](https://developers.openai.com/siwc/quickstart)。

维护者可查看 [申请 ChatGPT 接入](/guide/chatgpt-application)，了解真实申请入口、填写建议与后续条件。
