## 最终行为

普通划词翻译先呈现译文，再保留完整原文；单词词卡和相同译文的去重行为沿用现有规则。导航保留“翻译、读懂、词性与句法、用法、练习、记录”的顺序，窄卡片只占一行，鼠标滚轮与 Tab 能到达完整按钮。焦点滚动只调整导航本身，并换算页面缩放后的坐标；双轴滚动隔离避免斜向滚轮移动宿主页。

学习回答把追问、反馈和次级操作放进内部滚动内容。正文出现后，32px 的更多操作与停止按钮位于回答旁边，不再占用两条固定工具区。完整回答、原文、译文、追问和原有工具仍保留；菜单展开进入滚动布局，避免窄卡片的菜单被外框裁切。统一导航的阅读区右侧留白增加 15px，避开 macOS 浮动滚动条的命中区域，正文按可用宽度自然换行；没有增加固定操作区高度。独立阅读面板仍使用原来的固定工具与追问布局。

指针移动按动画帧合并，松开时提交最后接受的位置；取消、失焦、隐藏、视口改变和卸载使旧帧失效。已锚定卡片的位置更新不重复读取宿主选区，显式学习入口仍捕获选区。跟读文本的 UTF-16 偏移在片段内容变化时计算一次并复用，音频进度复用计算结果。流式回答连续增长只更新内部正文，首次出现、清空和状态变化才通知父卡片检查布局。真实组件测试的 40 个流式块只触发正文首次出现与完成的两次尺寸通知，全部内容仍渲染；手动阅读后追加的 12 个块不新增通知。

Popup 首页展示实际默认服务名称和适用的配置模型，完整名称自然换行，长模型最多两行并保留完整提示与无障碍名称。非模型服务不展示残留模型。只展示默认服务图标及其他分配数量，保留原有服务抽屉、模块顺序、隐藏配置、站点规则和设置提醒；提醒使用静态样式。

英文生产验证发现旧 UI 文案扫描器会把正文中的“文”改为“D”。忽略规则现在检查 `pre`、`code` 等祖先，保护其嵌套文字；Popup 的服务与模型摘要同样排除扫描，界面标签使用明确的本地化函数。测试使用实际指令、英文资源和 MutationObserver，覆盖语言切换与迟到文本，正常界面标签仍会翻译。

## 对照证据

基线是第一轮本地提交的不可变 Chrome 生产包；优化包由本轮最终源码构建。划词对照使用相同长原文、固定译文和本机流式回答夹具，Popup 对照使用相同合成配置，均在自己拥有的第二屏后台 Edge 中运行。正文首行断言聚合完整视觉行，分别检查生成中与完成后的真实段落，不能由标题可见或卡片尺寸稳定替代。

| 同一配置的测量 | 基线 | 优化版 |
| --- | --- | --- |
| 中文 280×180 导航高度 | 62px，两行 | 34px，一行 |
| 中文 280×180 普通正文滚动区 | 43px | 71px |
| 英文 280×180 导航高度 | 84px，三行 | 32px，一行 |
| 英文 280×180 普通正文滚动区 | 24px | 73px |
| 英文深色 360×200 学习回答可见滚动区 | 6px，正文首行不可见 | 77px，生成中与完成后首行完整可见 |

原文和每个完成的回答段落逐字校验，卡片手动位置与尺寸在流式采样中保持不变。导航键盘、垂直滚轮和斜向滚轮检查同时验证宿主页 HTML、文字、邻近布局和滚动不变。

生产拖动探针进入扩展实际隔离执行上下文，记录请求移动数、浏览器实际派发数、初始几何读取与同步移动读取。浏览器会合并输入，因此不能把不同轮次的实际事件数当作同样的负载。单帧合并、松开提交和过期回调由受控 RAF 的真实组件测试补充验证。矩形读取减少是工作量证据，不代表测量了 FPS 或所有硬件上的响应时间。

最终拖动对照两轮都请求 60 次移动，基线实际派发 20 次、卡片读取 41 次，其中 40 次发生在移动回调中；优化版实际派发 27 次、卡片只读取初始几何 1 次，同步移动读取为 0。两轮最终位移都是 36px、20px。学习流式回答的优化版 52 个采样中，左、上、宽、高变化均为 0；正文视口和首行另行检查，不能由这个稳定性结果替代。

优化版划词通过 12 组中英文、亮暗主题及普通/280×180/360×200 布局，全部 180 项检查通过；原生键盘依次展开菜单、访问每个按钮、关闭、输入并清空追问、返回翻译，每个按钮的完整矩形与五点命中均通过，未额外提交模型请求。21 张最终划词截图全部人工复核。Popup 通过 25 组布局、29 项检查及 25 张截图复核，包含英文界面的中文名称与模型“文”。基线报告保留关键内容不足、旧导航和英文扫描等预期失败观察，`ok: true` 只表示基线必需契约与清理完成。

两套最终专项未记录未捕获错误或外部请求；划词只收到本机夹具响应，Popup 的启动阶段与配置检查阶段 HTTP 尝试均为 0。每轮划词 43 个、Popup 55 个前台样本均为用户的 Google Chrome，临时 Edge 没有成为前台；四轮均完成自有浏览器关闭与 profile 删除。精简数据见[浏览器摘要](./assets/key-information-space-20261009/browser-summary.json)，源码、脚本及生产包指纹见[产物来源](./assets/key-information-space-20261009/production-provenance.json)。完整报告、全部截图和验证日志保留于 `/Users/thinkstu/Desktop/copy/artifacts/key-information-space-20261009/`，以 `selection`、`popup`、`validation` 目录为准；诊断轮次单独保存，不计为最终通过。

## 验证与复现

使用 `scripts/testing/run-selection-key-information-test.cjs` 与 `scripts/testing/run-popup-key-information-test.cjs`，复现命令见[测试文档](../testing.md)。脚本只启动自有临时 profile，所有截图前后采样前台进程；临时 Edge 若抢到前台即停止并按归属清理。结束后确认浏览器关闭、profile 删除，测试期间的外部请求、错误与焦点样本写入报告。

最终定向验证为 17 个测试文件、493 项通过，包含服务第一轮回归，不能与其 183 项重复相加。类型检查与测试分类审计通过；Chrome、Firefox、userscript 生产构建、userscript verifier 与扩展 manifest 检查通过。userscript 为 1,959,477 字节。页面缩放 50% 和 200% 的导航坐标由真实组件 setup 与模拟缩放矩形回归验证，生产浏览器矩阵仍以 100% 页面缩放运行。

文档构建通过。完整 `docs:check` 在基线源码 `854ce15d5` 的独立临时归档和本轮都因缺少 `/storybook/?path=/docs/foundations-colors--docs` 产物而失败，本机也没有 Storybook CLI（`spawn storybook ENOENT`）；没有将它记为通过。另行只读运行原有静态产物检查，排除缺失的 Storybook 子站后，79 页、4149 个链接、773 个锚点和 156 张图片均通过；仓库校验脚本与 Storybook 依赖未改动。

本机夹具验证实际生产 UI、后台消息与流式展示，不证明供应商翻译质量、音频可听性、模型下载或真实网站全覆盖。Popup 使用普通扩展标签页，几何不代表原生工具栏打开的尺寸与速度。配置模型可以被自定义请求体覆盖，因此摘要不声称它是实际服务端使用的模型。Firefox 只完成构建，没有实机运行证据；没有运行全量回归。
