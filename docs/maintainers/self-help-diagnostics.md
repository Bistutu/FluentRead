# 首次翻译与本地自助诊断

Popup 首启直接在一屏展示七种语言的原生名称和确认按钮，无欢迎、下一步或返回步骤；不重置已有用户的语言、服务、模型或网站偏好。首次阅读提示只在翻译计数为零、插件开启、当前网站可用且没有凭据提醒时出现。全文会话开启不等于翻译成功：只有内容运行时的 `toolbarStatus: translated` 才显示译文就绪；等待、失败和无候选分别呈现当前动作。

确认前的语言选择仅预览，不提交持久偏好。方向键和 Home/End 在单一 Tab 单选组内选择，确认期间冻结控件，只提交当次选择。当前保存确认成功后按 `saved` → 归属复验 → `confirmed` 一次交接，立即预加载并进入主菜单，没有 1.2 秒完成动画或固定等待。失活、关闭、卸载及初始语言变化使旧事件、排队焦点和迟到回复失效；已发出的保存允许完成，但不能借用新上下文宣布成功。已确认且已保存的菜单交接在缓存恢复后可继续采用已加载模块；加载失败提供显式重开，以重新加载被浏览器缓存为失败的 import。首启保存无法确认时保留选择，显示七语本地短文案并允许再次确认，不指向尚不可用的设置页。

配置暂时不可读不代表新用户。Popup 先等待既有 `configReady`，再检查配置服务的只读 `getConfigHydrationStatus()`；异步组件、语言和字体准备完成后再检查一次。`blocked` 时显示固定的安全失败说明和手动重开入口，不挂载使用默认值的首次引导、不保存或重置配置。该状态派生自已有初始化和写入保护标志，不改变配置水合、迁移或持久化算法；其他调用方必须先等待 `configReady`，不能把这个状态查询当作迁移完成通知。

用户在失败现场可手动重试、检查当前服务或网站范围。凭据/权限、模型配置和普通配置故障按“检查服务 → 重试 → 关闭”提供动作；全文会话仍开启时，一次明确重试复用既有 `restore → fullPage` 路径，不要求先单独点击主按钮还原。主按钮继续保留正常还原语义。重试保留来源标签页和文档归属，忙碌时禁用；导航、关闭或配置变更使旧动作失效。不会自动切换用户选择，也不建立额外的自动重试循环。

修复链接只用 `returnTabId` 携带来源数字 ID，不包含来源 URL。服务入口同时保留服务 ID；网站范围入口指定 `settings-sites` 与 `target=adaptation`。此外，Popup 的“划词翻译 → 更多设置”也附加已有来源 ID，在划词设置顶部展示不带修复说明的返回按钮；其他普通设置导航不附加。返回动作只在明确点击后读取并激活来源标签页当前的网页，保留设置页；所属视图、分区、配置切换或页面隐藏会使尚未完成的查询失效，已提交的标签激活无法撤回。网站适配面板顶部复用紧凑返回条，避免定位面板后返回入口落在视口上方；其动作同时受设置视图、当前分区、配置身份和网站适配/翻译范围上下文保护。原网页已关闭时解释原因，不选择其他网页代替。Options 仅允许目标分区的已登记 panel/搜索目标路由，不接受任意 DOM selector；本轮修复原入口只识别具体搜索目标、忽略 panel ID 的缺口；网站修复完整生产闭环已验证，仍保持分区白名单限制。

有效修复链接首次挂载且服务匹配时，键盘焦点直接进入当前服务的连接检查按钮；按钮因缺少必填配置等原因禁用时，落到当前服务标题或配置区域。聚焦本身不检测、不保存，也不激活窗口。普通设置页不触发；已有用户焦点、等待期间的键盘/指针/焦点变化、隐藏、切换或卸载都会放弃旧聚焦。安全来源解析由返回组件与小型焦点模块复用，单个页面实例仅尝试一次。

## 公共诊断契约

`src/services/diagnostics/index.ts` 提供纯函数：

- `diagnoseFailure(error, context)`：优先使用结构化 kind、HTTP 状态及 Retry-After 分类；旧供应商仅把消息作为内部归因线索，结果不保留原始消息。
- `normalizeDiagnostic(value)`：跨消息边界只接收已知 code，重新生成文案键和允许动作，忽略传入的任意文案、动作与额外字段。
- `getDiagnosticText`、`getDiagnosticUiText` 及诊断组件直接使用的 i18n key：从已注册的七语资源读取诊断、动作、报告及首次使用/返回原网页文案，资源位于 `src/core/i18n/messages/self-help/`。界面沿用既有按需加载，未就绪时回退中文，资源到达后更新文案；语言变化保留预览和限流截止时间。服务检查结果保存安全资源 key，逐密钥、逐服务及独立错误同步更新，不重新请求、不翻译原始错误。配置加载前的启动反馈以内置七语短文案按浏览器语言呈现，不依赖配置或完整语言包。脚本版固定语言资源的发布身份保持既有约束。
- `buildDiagnosticReport(input)`：生成白名单 JSON 数据，无存储、日志、下载或网络副作用。

分类包含取消、离线、无正文、不支持的页面、来源已关闭、扩展上下文更新、网页组件未接入、凭据或权限、模型配置、普通配置、配置保存无法确认、限流、超时、网络、服务异常与未知失败。`configuration-save` 明确说明连接检查尚未开始，表示无法确认保存回执，不据此断言后台一定没有写入。用户取消不标记供应商不可用。只有确定缺失的标签页返回 `source-closed`，提示重新打开所需网页再打开扩展；它没有刷新不存在标签页的动作，也不会转向其他标签页。一般读取错误不据此判为关闭，空 URL 也不代表浏览器内部页。

全文通过既有 `fullPageTranslationState` 通知和 `getFullPageTranslationState` 查询附带安全 `diagnostic`；菜单回执使用相同字段。Popup 只接收当前顶层文档的状态；握手的 documentToken 区分同 URL 刷新，旧查询不能覆盖新通知。加载完成时再次查询；受信广播带来尚未绑定的文档标识时，只触发当前标签页的只读复验，不直接采用广播内容。查询期间的通知合并处理，不启动翻译请求或定时轮询。权威计数同步不会清掉诊断，服务或连接指纹变化仍使旧操作失效。内容端按失败 owner 保留分类，避免一个段落成功清掉其他段落仍存在的失败。开始、恢复、切换路由及真正修复相应失败后清理诊断。

无正文仅在完整根扫描结束、文档不处于 loading、从未发现候选且没有已有翻译目标时报告。目标语言相同、离屏等待、翻译返回原文均不据此报告无正文。动态文档后续发现候选会清除无正文提示。

限流截止时间从真实失败开始计算，重开 popup 不重置。界面只限制手动重试，没有自动请求。服务检测的重试标签始终使用当前语言的固定动作名称（例如法语 `Réessayer`），等待期间由 disabled 状态限制，不回退为英文等待文案。设置页对免费池各供应商分别冷却，单路限流不阻塞正常启用池。超过浏览器32位定时器范围的等待分段唤醒并复验截止时间。

## 本地报告与隐私

失败默认只在翻译区底栏右侧显示 24px 状态入口，与嵌套的网站规则同行；网站模块被隐藏或独立排序时，状态入口仍属于翻译区，不重复也不消失。原因、恢复动作、预览和忽略操作均在用户明确打开非模态浮层后才挂载，不增加主区高度。浮层按 Popup 可见空间定位并限制高度；外部点击和焦点离开可收起且不抢焦点，内部滚动保持，祖先滚动重新定位，入口滚出可见区域则收起。Escape/浮层关闭按钮清除预览并归还入口焦点；“忽略提示”才移除诊断并返回翻译按钮。 桌面入口保持24px；coarse或明确Android平台标记下，入口宿主与按钮均使用44px真实盒子，保留小图标视觉且不覆盖相邻网站规则。摘要、入口无障碍标签与恢复文案沿用七语按需包和加载代次；包迟到时隐藏摘要也刷新，已打开浮层同步重测高度。

报告默认不存在。用户先展开详情、再点击“预览诊断”才构造内存中的 JSON；点击“导出 JSON”才创建本地下载。预览会在诊断切换时清除，下载 URL 与计时器会回收；没有自动发送、剪贴板写入或持久诊断日志。

白名单仅允许 schema 版本、诊断代码和剩余等待、feature 类别、服务类别、严格数字扩展版本及在线布尔状态。不包含 API Key、令牌、请求头、请求 ID、模型名、自定义服务名、错误原文、完整 URL、页面正文、配置或调用堆栈。调用方不得扩展报告为完整配置或原始异常转储。

## 验证与集成边界

专项脚本 `scripts/testing/run-self-help-ui-test.cjs` 使用临时 Edge profile、后台可见的第二屏窗口与本地 HTTP 供应商夹具，用实际参数 `--extension <production-dir>` 和 `--artifacts <evidence-dir>` 显式提供产物及证据目录；`--locales true --refresh-rounds 3` 选择七语与三轮刷新专项。`--live-default true` 额外对公开合成文本执行一次默认免费池在线烟测，报告区分该次结果与本地夹具。先构建再运行；本地夹具不构成在线供应商验收，单次烟测也不构成全部供应商、长期稳定性、Firefox、Safari 或移动真机验收。不得复用日常 profile 或启用前台抢焦点的替代启动方式。

主要共享文件是语言首启组件、popup 首启根组件和相关测试脚本、popup 组装/控制器、`OptionsApp.vue` 的白名单路由、`SettingsSections.vue` 的网站面板与缓存生命周期、配置应用的只读状态出口、全文状态与菜单回执、服务配置及共享 `ServiceRepairReturn.vue`、连接测试 handler、Vitest 注册和测试归属清单。涉及其他任务的设置页改动时须保留这些路由、来源与失活门禁。网页识别算法、供应商选择算法和平台触摸适配仍由各自 feature 负责。其他 feature 可复用纯诊断及安全 UI，但必须自行提供实际失败原因和受生命周期保护的动作。
