# 首次翻译与本地自助诊断

Popup 保留原来的界面语言选择，不重置已有语言、服务、模型或网站偏好。首次阅读提示只在翻译计数为零、插件开启、当前网站可用且没有凭据提醒时出现。全文会话开启不等于翻译成功：只有内容运行时的 `toolbarStatus: translated` 才显示译文就绪；等待、失败和无候选分别呈现当前动作。

用户在失败现场可手动重试、检查当前服务或网站范围。重试保留来源标签页和文档归属，必要时先恢复原文；导航、关闭或配置变更使旧动作失效。不会自动切换用户选择，也不建立额外的自动重试循环。服务修复链接携带服务 ID 与来源 tab ID；设置页提供明确的返回按钮，原网页已关闭时解释原因，不选择其他网页代替。

## 公共诊断契约

`src/services/diagnostics/index.ts` 提供纯函数：

- `diagnoseFailure(error, context)`：优先使用结构化 kind、HTTP 状态及 Retry-After 分类；旧供应商仅把消息作为内部归因线索，结果不保留原始消息。
- `normalizeDiagnostic(value)`：跨消息边界只接收已知 code，重新生成文案键和允许动作，忽略传入的任意文案、动作与额外字段。
- `getDiagnosticText`、`getDiagnosticActionLabel`、`getDiagnosticUiText`：从已注册的七语资源读取诊断、动作、报告及首次使用/返回原网页文案，资源位于 `src/core/i18n/messages/self-help/`。界面沿用既有按需加载，未就绪时回退中文，资源到达后更新文案；语言变化保留预览和限流截止时间。服务检查结果保存安全资源 key，逐密钥、逐服务及独立错误同步更新，不重新请求、不翻译原始错误。配置加载前的启动反馈以内置七语短文案按浏览器语言呈现，不依赖配置或完整语言包。脚本版固定语言资源的发布身份保持既有约束。
- `buildDiagnosticReport(input)`：生成白名单 JSON 数据，无存储、日志、下载或网络副作用。

分类包含取消、离线、无正文、不支持的页面、扩展上下文更新、网页组件未接入、凭据或权限、模型配置、普通配置、配置未保存、限流、超时、网络、服务异常与未知失败。配置未保存明确表示没有向供应商发起检测，用户取消不标记供应商不可用。

全文通过既有 `fullPageTranslationState` 通知和 `getFullPageTranslationState` 查询附带安全 `diagnostic`；菜单回执使用相同字段。Popup 只接收当前顶层文档的状态；握手的 documentToken 区分同 URL 刷新，旧查询不能覆盖新通知。加载完成时再次查询；受信广播带来尚未绑定的文档标识时，只触发当前标签页的只读复验，不直接采用广播内容。查询期间的通知合并处理，不启动翻译请求或定时轮询。权威计数同步不会清掉诊断，服务或连接指纹变化仍使旧操作失效。内容端按失败 owner 保留分类，避免一个段落成功清掉其他段落仍存在的失败。开始、恢复、切换路由及真正修复相应失败后清理诊断。

无正文仅在完整根扫描结束、文档不处于 loading、从未发现候选且没有已有翻译目标时报告。目标语言相同、离屏等待、翻译返回原文均不据此报告无正文。动态文档后续发现候选会清除无正文提示。

限流截止时间从真实失败开始计算，重开 popup 不重置。界面只限制手动重试，没有自动请求。设置页对免费池各供应商分别冷却，单路限流不阻塞正常启用池。超过浏览器32位定时器范围的等待分段唤醒并复验截止时间。

## 本地报告与隐私

报告默认不存在。用户点击“预览诊断”才构造内存中的 JSON；点击“导出 JSON”才创建本地下载。预览会在诊断切换时清除，下载 URL 与计时器会回收；没有自动发送、剪贴板写入或持久诊断日志。

白名单仅允许 schema 版本、诊断代码和剩余等待、feature 类别、服务类别、严格数字扩展版本及在线布尔状态。不包含 API Key、令牌、请求头、请求 ID、模型名、自定义服务名、错误原文、完整 URL、页面正文、配置或调用堆栈。调用方不得扩展报告为完整配置或原始异常转储。

## 验证与集成边界

专项脚本 `scripts/testing/run-self-help-ui-test.cjs` 使用临时 Edge profile、后台可见的第二屏窗口与本地 HTTP 供应商夹具，必须显式提供 production 扩展目录与证据目录。`--live-default true` 额外对公开合成文本执行一次默认免费池在线烟测，报告区分该次结果与本地夹具。先构建再运行；本地夹具不构成在线供应商验收，单次烟测也不构成全部供应商、长期稳定性、Firefox、Safari 或移动真机验收。不得复用日常 profile 或启用前台抢焦点的替代启动方式。

主要共享文件是 popup 组装/控制器、全文状态与菜单回执、服务配置组件、连接测试 handler、Vitest 注册和测试归属清单。网页识别算法、供应商选择算法和平台触摸适配仍由各自 feature 负责。其他 feature 可复用纯诊断及安全 UI，但必须自行提供实际失败原因和受生命周期保护的动作。
