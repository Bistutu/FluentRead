## 操作执行时合并

数组写入改为接收最新只读列表的意图函数，在保存队列执行时计算补丁。普通对象补丁只允许总开关布尔值，防止新的完整数组写入再次绕过队列。组件仍存活时沿用字段签名缓存同步配置；卸载后，已接受任务从仍运行的共享配置 store 读取并规范化列表，不依赖已经取消订阅的界面快照。

- 新建库保留点击时的默认名称与目标语言，执行时重新检查容量、分配不冲突的 ID 并避开同名。
- 内置库执行时重新检查 preset 身份。若其他页面已安装，只选择已有库，不覆盖它的名称、词条或启停；已存在时不会因为库容量已满而误报失败。
- 排序按钮携带库 ID 和方向，执行时在当前顺序中移动一格，保留外部新增项。目标已删除或已到边界时不写入，也不误报失败。
- 导入固定已经确认的解析结果与警告接受事实，执行时在最新列表后追加，重新分配 ID 并检查总库数、总词条容量。之后修改文本、格式或警告选项不会改变已接受的导入内容。

没有变化的操作不发送请求，也不亮起新的保存成功状态。执行时超出容量保留原来的容量文案；传输或字段冲突失败仍回读配置，保留可重试的输入。

## 回执属于原操作

新建和内置库添加不会抢回用户在等待期间后来选择的库。导入用同步 revision 区分文本、格式、警告和弹窗会话，即使输入或开关发生 ABA 变化，旧回执也不能关闭新草稿。

“首次添加自动建库”继续校验新库 ID 和选择 revision；后续创建、填写草稿和延迟焦点只作用于原库及同一草稿对象。编辑确认框返回时同样检查确认前的草稿归属。组件卸载后不再更新选择、草稿、弹窗或焦点，但已接受的数据保存继续交给存活的配置服务。

## 配置服务边界

store 的最新运行时配置可能包含其他待确认补丁的乐观值，不等同于已落盘快照。组件计算补丁至配置客户端调用之间没有新增等待；客户端仍按该次调用的基线登记整字段 CAS。后台提交前若其他页面删除或修改同一 `glossaryLibraries` 字段，请求会拒绝并回读最新值，不自动把旧列表重新套用。无关字段更新可以正常保留。

组件卸载时共享 store 仍活着；这与整个浏览器页面被关闭不同。尚未交给配置客户端的组件本地队列不具备跨页面销毁持久化保证，本轮没有另建后台持久队列。
