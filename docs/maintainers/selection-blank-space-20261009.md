# 划词卡底部空白与短回答高度

本轮接续本地提交 `c053cda73`，针对用户确认的划词翻译／学习卡片调整布局。上轮的[关键内容空间报告](./key-information-space-20261009.md)记录其历史状态，本轮没有扩大到 Popup 或服务设置。

## 根因与行为

音频状态栏始终在布局中占据 36px，闲置时只通过 `visibility:hidden` 隐藏。学习模式还固定为 520px，回答区域人为保留至少一屏高度，以便滚过上方原文；因此短回答之后会留下大片空白。

闲置音频栏现在退出布局。自动卡在生成与播放期间单独锁住当时的外框高度，停止后恢复自然尺寸；这份临时高度不进入用户手动尺寸。手动拖动、缩放和流式生成仍沿用既有几何合同，播放栏出现时正文在其上方滚动，控件不覆盖文字。

学习短回答按实际内容收拢，长回答受父卡高度上限约束并在内部滚动。完整原文与译文默认收起，通过更多操作中的“查看原文”展开，再用“返回当前阅读”回到回答；原文 DOM 与内容仍保留。展开或收起的迟到回调不能移动新的选区或回答；隐藏对照时晚到译文不改变阅读位置。独立阅读面板保留原有对照布局。

## 同一生产夹具的测量

基线为上述提交的不可变 Chrome 包；优化包由当前源码构建。在隔离临时 Edge、第二屏后台窗口中使用相同的本机译文、流式回答与静音音频夹具。

| 测量 | 基线 | 本轮 |
| --- | --- | --- |
| 闲置音频栏占位 | 36px | 0px |
| 中文短回答自动卡高度 | 520px | 219.29px |
| 同一短回答追问框之后的留白 | 278.72px | 14px |
| 英文深色 360×200 手动学习卡正文视口 | 77px | 113px |
| 自动长回答内部滚动区／总内容高度 | 395／1029px | 431／573px |

长回答的上方对照改为按需展开，因此滚动内容总高度减少。回收的 36px 用于同尺寸手动卡的正文；不会自动缩小用户已经设置的外框。自动长回答的最后一行、复制、笔记和追问均能通过内部滚动访问。

优化版通过原有 12 组长原文布局、追加的 16 组短回答布局及自动长回答专项，全部 326 项检查通过。覆盖中英文、亮暗主题、自动／390px 窄屏／280×180／360×200，以及生成中、播放与停止。4 次原文／译文音频周期的逐帧左、上、宽、高最大变化均为 0；手动学习流式采样保持外框。正文首行和实际滚动视口单独检查，不能由卡片稳定代替。

优化版 63 张截图已分工逐张查看：31 张核心、音频、对照与长文截图，16 张短译文截图和 16 张短学习截图。127 个前台样本均为用户的 Google Chrome；基线 125 个样本也相同。两轮均关闭自有浏览器并删除 profile，没有未捕获异常、外部页面请求或外部供应商响应。

## 验证范围

受影响的 6 个测试文件共 184 项通过：划词生命周期 84、真实阅读组件与流式布局 13、阅读生命周期 16、实际渲染审计 40、阅读展示 29、主题 2。新增测试覆盖临时高度撤销、失败与迟到状态、关闭和卸载、手动尺寸优先、展开／返回、晚到译文与用户滚动。生命周期的 4 文件执行日志为工具输出的明确转录摘要，其他日志为原始 stdout；没有将摘要伪装成原始记录。

文档构建、类型检查、测试分类审计、Chrome／Firefox／userscript 构建、userscript verifier 和扩展 manifest 检查通过。userscript 从 1,959,477 增至 1,961,367 字节，增加 1,890 字节；体积上限相应从 1,960,000 调整到 1,962,500 字节，所有协议与运行边界校验保留。

完整 `docs:check` 仍因既有的 Storybook 子站产物缺失失败，与上一轮记录相同，未记为通过。只读临时校验副本排除该缺失子站后，79 页、4149 个链接、773 个锚点和 156 张图片通过；正式校验脚本没有改动。维护报告目录本来不参与站点构建，对照资产用于本地审阅。

复现主专项：`node scripts/testing/run-selection-key-information-test.cjs --blank-space --phase optimized --extension-dir .output/chrome-mv3 --playwright-root <Node包目录> --artifacts-dir <证据目录>`。第一轮优化发现长回答内层未随外框收缩，已修复嵌套 flex 高度，诊断轮次单独保留，不计为最终通过。

本机夹具只证明指定生产 UI 与事件路径。静音 WAV 不证明可听性；Firefox 只有构建证据，没有实机验证。本轮没有运行全量回归，没有修改或构建参考项目，也没有上传分支或创建 PR。
