# 服务工作区空间与滚动优化

本轮以 `854ce15d5` 为基础，先处理翻译服务设置的目录、模型和连接配置。它是界面优化的第一轮，后续 Popup 与划词卡的结果见[关键内容空间报告](./key-information-space-20261009.md)。本轮没有改变配置服务与默认服务的边界，也没有修改翻译提供商或本地模型推理算法。

服务目录缩小无信息的边距，保留完整名称、自然换行和至少 44px 的命中高度。详情区去掉重复外框和过大的标题留白，让模型与 API Key 更早出现。英文目录标题允许换行，避免标题、数量与自定义服务按钮相互遮挡。桌面目录与详情分别滚动；窄屏目录关闭后由工作区承接配置滚动。切换服务、明确再次选择当前服务或离开后重新进入会从关键字段开始；持续编辑时替换配置对象保留当前位置。

目录滚动事件合并到同一动画帧，复用分组位置缓存。搜索、折叠、目录显隐、分组尺寸或字体变化才重建几何；用户手势接管后解除导航固定高亮。停用、上下文改变和卸载取消旧帧、观察器及迟到的导航操作。

本地翻译模型页复用现有 `useSettingsActionContext`。隐藏、缓存停用、上下文改变或卸载会退订页面进度并取消归属于该页面的试译，旧确认、DOM 事件和回包不能修改新页面。后台模型下载继续，返回时重新读取权威状态。按模型索引读取任务，避免每次查找及分配默认状态；快照修订号阻止迟到的初始缓存或状态读取覆盖较新的删除结果，有效状态回包仍可结束加载。

## 已取得的证据

保留的基础生产包与优化生产包使用相同合成配置，在隔离后台 Edge 中对照。中文、英文，浅色、深色，以及 1440×900、1024×700、820×600、390×720、1440×480 共 20 组布局；浏览服务、搜索、折叠和查看模型不改变默认服务。窄屏外部配置入口分别验证切换服务和重开同一服务，返回后只读等待实际滚动归零，不由测试人工修正位置。

| 测量范围 | 基线 | 优化版 |
| --- | --- | --- |
| 首个 API Key 在详情内容中的位置 | 对照起点 | 提前约 24–33px |
| 常见单行目录条目高度 | 桌面约 60px；窄屏约 54px | 约 44px；长名称自然增高 |
| 标题区纵向 padding 与 margin 合计 | 桌面 40px；窄屏 32px | 24px |
| 每组 48 帧目录滚动探针中的矩形读取 | 225 次 | 0–10 次 |
| 20 组滚动探针的矩形读取合计 | 4500 次 | 20 次 |

矩形探针只统计目录滚动区及分组的 `getBoundingClientRect` 调用，排除截图和指标采集，不能据此推断整页 FPS、翻译服务速度、模型性能或其他硬件表现。页面生命周期测试使用真实 Vue 组件与受控存储、确认及后台端口，证明取消和归属行为，不证明真实模型下载、GPU 推理或翻译质量。Firefox 仅完成构建，未进行真实浏览器运行验证。

最终生产浏览器轮次通过 20 组布局、20 次滚动探针及 16 项交互记录；全部布局的目录标题、数量与自定义服务按钮无重叠断言通过，20 张最终截图也已人工复核。测试动作期间未记录控制台错误或 HTTP 请求尝试。尺寸变化导致少量缓存重建，因此单组读取为 0–10 次，并非所有滚动都零读取。精简结果见 [浏览器摘要](./assets/service-workspace-density-20261009/browser-summary.json)。

浏览器使用 `macos-background-cdp`、`launchservices-no-foreground` 和第二屏正常可见的 `background-visible-no-focus` 窗口，`browserFrontmost=false`；测试前后前台应用均为用户的 Google Chrome，只操作本任务临时 Edge profile，结束后关闭并清理。完整最终报告、20 张截图与验证日志保留在 `/Users/thinkstu/Desktop/copy/artifacts/service-workspace-density-20261009/`，以其中 `baseline` 与 `optimized` 目录为准。

## 源码与构建验证

定向验证为 6 个测试文件、183 项通过；类型检查与测试分类审计通过。Chrome、Firefox、userscript 生产构建、userscript verifier、扩展 manifest 检查和文档构建通过。本轮未运行全量回归，也未请求翻译服务、检查连接或下载模型。

userscript 构建同时补齐语言清单已引用但缺失的五份带哈希资源：西班牙语、法语、日语、韩语和俄语。它们由现有生成流程产出，不代表本轮改写这五种语言的文案。本轮仅使用 FluentRead 自身的 Vue、配置、消息及测试架构，没有借鉴、修改或构建参考仓库。
