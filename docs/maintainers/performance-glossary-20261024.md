# 术语库通知开销与设置页活跃边界（2026-10-24）

本轮基于本地性能集成提交 `563a171ce`，继续处理术语库设置的重复计算。未使用参考仓库，没有更改依赖、版本、权限或 CSP，也没有上传或创建 PR。

## 问题与行为

设置页保留已访问的表单实例，术语库之前没有活跃边界。每次配置通知都会重新规范化所有库和词条，包括翻译计数变化产生的通知。合法的 10 个库、每库 500 个词条，在 20 次仅计数变化时会额外处理 100,000 个词条；这描述组件自身的工作量，配置存储层仍有独立的校验与通知成本。

现在使用完整术语库字段签名识别库内容是否变化，内容相同时保留现有规范化列表；隐藏或 KeepAlive 停用时只保留最新通知，恢复时处理最新快照。父设置页继续保留同一组件实例，并将当前分区与缓存活跃状态传给术语库。

显示刷新暂停不取消用户已接受的保存。函数补丁在保存队列执行前同步最新权威快照；新建、内置库添加、排序和导入则在构造完整列表前同步，避免隐藏时仍打开的浮层使用过期列表。恢复与回执继续保留选中库和未提交草稿的归属。完整签名包括名称、条目 ID、启停和所有术语字段，不使用只表达翻译内容的版本摘要。

## 验证范围

真实术语库 SFC 的 72 项用例通过；父设置页生命周期与 UI 约束的 162 项用例通过。最终文件头、行为所有权及两项设置回归合计 1,318 项通过，其中包含上述 162 项，不重复加总。类型检查、Chrome/Firefox 构建、用户脚本构建及 verifier、扩展 manifest 校验通过。精确用例数、原始红例、工作量计数、产物比较及最终提交见工作区 `workspace-data/evidence/performance-integration-20261024/glossary/summary.json`。

最终 Chrome 目录为 62,998,400 字节，相比上一轮本地提交增加 605 字节，相比已核对的主线 `d580021e1` 少 76,194 字节；用户脚本仍为 1,869,057 字节。文件数、权限与 CSP 不变，源码与产物摘要记录在 `glossary/artifact-validation.json`。远程主线已通过连接器只读核对；shell 的 fetch 曾因 DNS 不可用失败，没有更新或修改远程引用。

可见状态的签名计算仍需遍历术语库，不把跳过规范化解释为零成本；隐藏通知只更新快照引用。合成工作量计数不代表浏览器帧延迟或真实网站加速比例。新组合产物的真实浏览器验收仍待补齐。

5,000 条测试数据的一份签名为 397,951 字符，UTF-16 文本载荷上界为 795,902 字节，字符串对象和其他堆开销另计。这是夹具计数，没有进行实际堆测量。最新快照仅保留库数组引用与启停布尔值，既不复制库数组，也不额外持有通知中的其他配置数据。

另有一个前后实现都存在的保存边界：静态数组构造完成后、队列微任务真正发送前，如果同步发生外部修改，已捕获的完整数组仍可能覆盖该修改。本轮没有把已接受的静态操作重写为可重放编辑，因此不声称消除了所有保存竞争；该问题留作独立交互修复，并由后续反例界定操作身份与冲突行为。
