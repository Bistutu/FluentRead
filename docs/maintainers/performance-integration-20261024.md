## 词书搜索的工作量

词书原先在每次搜索输入时，为所有符合类型和状态的词条拼接完整搜索文本，并对全部匹配项重新排序，之后才取每页 50 条。现在类型/状态筛选及排序独立于查询，非空搜索才读取正文索引。

索引额外保留的文本最多 4,194,304 个 UTF-16 code unit，对应至多约 8 MiB 文本载荷，Map 与对象开销另计。达到预算即停止索引后续词条，它们仍按原有完整文本匹配；没有缩短上下文、丢弃语言或延迟输入。清空查询会读取空索引并释放旧文本和词条引用。

以下使用真实生产 computed 表达式与 Vue 响应式，统计 getter 和排序字段访问，不是浏览器帧延迟：

| 5,000 词条，连续输入 `reading` | 原实现 | 候选 |
| --- | ---: | ---: |
| 紧凑正文，首次非空查询译文读取 | 5,000 | 5,000 |
| 紧凑正文，后续六次译文读取 | 30,000 | 0 |
| 紧凑正文，后续六次上下文读取 | 240,000 | 0 |
| 两种语料，后续六次排序字段读取 | 59,988 | 0 |
| 长正文，首次非空查询译文读取 | 5,000 | 5,001 |
| 长正文，后续六次译文读取 | 30,000 | 23,274 |

紧凑语料的完整索引为 1,742,780 字符，5,000 条均可缓存。每条八段、每段 400 字符的长语料完整索引需 18,702,780 字符，实际仅缓存 1,121 条、4,193,661 字符；首次多读取一次是探测首条无法容纳的完整词条，之后不再为预算探测拼接后续溢出项。两种语料空查询正文读取均为零，清空查询后缓存条数为零，匹配总数、顺序及前 50 项与原实现一致。

真实 SFC 及直接消费者 107 项通过，覆盖全部搜索字段、跨字段短语、类型/状态/到期筛选、稳定排序、分页重置与收缩、嵌套字段新增/修改/删除、条目替换/删除，以及超预算尾部上下文完整匹配。保留原有 KeepAlive 会话与朗读语义。

## 个人校订与动态页面

个人校订的语境观察器原先对每个无关新增/删除元素都枚举全部活动译文。现在先探查变更子树中已有的所有权索引；最多读取 64 个节点，超过预算就沿用原来的活动 owner 范围判断，避免把全页译文扫描换成大子树的无界 JavaScript 遍历。标题和路由变化仍执行完整失效检查。

封闭 Shadow DOM 无法通过宿主的 `shadowRoot` 遍历。为保留已有组合树语义，已注册 metadata 的 owner 使用弱引用登记，每批变更最多惰性读取一次，并根据当前根识别封闭树；包括注册后由普通/open 树移入 closed，以及 closed A 移到 B 的情况。没有强引用 owner 或 state，状态替换/恢复时立即清退旧登记，观察器取消时释放状态订阅。

真实生产模块的 40 个无关元素变更，弱引用读取次数如下：

| 场景 | 原实现 | 候选 |
| --- | ---: | ---: |
| 300 个普通 owner，无 metadata | 12,000 | 0 |
| 上述普通 owner，加 1 个外部个人校订单元 | 12,040 | 1 |
| 300 个 owner 都有 metadata | 12,000 | 300 |

密集 metadata 页仍需每批读取一次；这里没有声称所有动态场景都不再扫描。50,000 节点的变更子树验证了 64 节点探针后回退，真实关联变化仍会失效旧语境。开放/封闭根、跨根移动、合成段、仅译文、取消，以及持续恢复和状态替换均由真实状态机消费者验证。
