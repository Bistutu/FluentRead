# ChatGPT plan availability

**ChatGPT plan integration is not available in current public FluentRead releases.** The required OpenAI application and approval have not been completed, so there is no public sign-in flow for this service yet.

Continue choosing an available provider in **Settings → Translation services**. Existing provider settings and completed translations are retained. If you previously saved a ChatGPT plan service or model, choose an available provider for the features you need; you do not need to delete the saved configuration.

A future public release will provide a complete flow that starts authorization from the extension and returns automatically. Account eligibility, models, and usage limits will depend on OpenAI's actual permissions. A ChatGPT Plus or Pro subscription alone does not enable this integration in FluentRead.

See the official [Sign in with ChatGPT overview](https://developers.openai.com/siwc/quickstart) for availability and plan usage.

Maintainers can read [Apply for ChatGPT access](/en/guide/chatgpt-application) for the actual application form, suggested information, and next steps.
