# 图片翻译

识别网页图片中的文字，在原图上看译文。先在 **设置 → 图片/漫画翻译** 中开启功能。

头像、常见图标、Logo、表情、视频封面和过小的图片会尽量跳过，减少浏览干扰。X／推特等网站的视频在尚未播放、只显示预览图时，也会根据播放器或封面标记跳过。小图即使被放大，也可能不会显示悬浮入口。如果需要翻译的图片没有出现图标，可以右键选择翻译图片，或打开清晰原图后再试。

设置统一为 **图片/漫画翻译**。顶部先选择原文语言、目标语言和翻译服务；下方分别设置网页图片、漫画连续翻译和圈选翻译。**入口与缓存**、**识别资源与下载**、**支持的网站** 默认收起，按需展开。

网页图片默认使用 **PaddleOCR（标准模型）**，适合普通图片、截图和漫画文字；也可切换到 **Tesseract（轻量模型）**，按原文语言准备语言包。新安装、旧配置缺少识别方式或值无效时使用 PaddleOCR；已有明确保存的引擎选择会保留。PaddleOCR 首次翻译准备约 30 MB 识别模型，与漫画共用已有资源，不重复下载。选择识别方式本身不开始下载，也不会把单图操作改成漫画连续翻译。更换方式后旧译图缓存失效，下次翻译重新识别；效果因图片而异，可以对照原文判断。

普通图片会按行距、字号和对齐位置，将同一段落的换行文字合起来翻译，标题、列表项和不同栏尽量保持独立。译文在整段范围内重新换行，沿用段落对齐并限制字号；清除原文时只处理原来的文字行框，减少对行间图案的影响。**文字 → 原文对照** 也按完整段落阅读。复杂布局或识别错误仍可能影响分组，可随时切回原图核对。

普通图片的本地排版与背景修补已减少重复计算和大图内存占用；生成译图时使用异步无损 PNG 编码，等待期间仍可取消。首次识别的模型准备和翻译服务响应仍会影响总等待时间。

以网页图片形式加载的 SVG 流程图也支持图片翻译，可切换原图或打开文字面板核对结果。

透明背景上的浅色或深色文字均可识别，译图未修补区域保留原图透明度。JPEG 的识别方向与网页显示方向保持一致。

WebP、GIF、BMP、AVIF 和 ICO 也使用同一图片翻译流程。动图生成静态译图，可随时切回原动图；小尺寸 ICO 等图标可能跳过悬浮入口，需要时可右键主动翻译。

## 漫画连续翻译

连续翻译开启后，快速滑过的新页会等滚动停稳约 180 毫秒再开始识别，避免把中途页面积压进队列；已完成的译图仍立即显示。跳到远处未翻译的新页时，停稳后会取消已离开保留范围的旧任务，让当前页接着处理。手动开启和重试立即执行。后台提前翻译仍按设置的页数，在停稳后继续。

本地漫画模型在连续阅读和短暂暂停后复用，空闲约三分钟后释放内存。初始化过程中暂停会立即恢复原图，已开始的模型准备可继续供重新开启时复用；超时或故障会停止并允许重试。首次模型准备、复杂页面识别和文字服务请求仍可能需要等待。

目前已适配 [MANGA Plus by SHUEISHA](https://mangaplus.shueisha.co.jp/) 的漫画阅读器和 [Pixiv](https://www.pixiv.net/) 的作品阅读页。进入阅读页后，点击悬浮球旁的漫画按钮即可开始；不会自动打开右下角阅读面板。首次点击且缺少资源时会说明下载用途和容量，确认 **准备资源并开始** 后关闭说明并准备缺失资源。选择 **稍后** 或关闭说明不会开始下载。

普通全文翻译悬浮球默认关闭；开启后默认悬停展开，移开鼠标或按 Escape 会收回边缘。上方是网页翻译按钮，中间只显示圆形品牌图标，漫画阅读页在下方显示 32 像素漫画按钮；全文翻译状态只显示在网页翻译按钮上。悬停模式下，漫画工具在闲置约 2.5 秒后收回；也可在悬浮球进阶设置中选择始终显示。关闭普通悬浮球时，可保留默认常驻的独立漫画按钮。在 **图片/漫画翻译 → 独立漫画按钮** 可关闭或恢复它；已保存的显隐偏好继续生效。插件总开关或漫画连续翻译关闭时不显示入口。

- 点击一次开启当前章节的连续翻译。优先处理当前可见页，默认提前处理后续 **3 张图片**；可在设置中选择 **0–5 张**，0 表示只处理当前可见页。只提前处理网站已经加载的图片，不会主动加载整章或下一章。更多提前页会增加设备处理量及服务请求。
- 当前页完成后立即显示，后续页在后台准备；准备好的页面滚动进入视口时直接显示译图。网站尚未加载的图片仍需先加载，翻页过快也可能需要等待。仅滚动不会取消仍在处理的同一图片；切走标签页会暂停启动新页面任务。
- 最近两张已经加载的前页可在像素预算内保留结果，不额外启动识别；另一张尚在处理时，返回这些页面也能直接显示。更远的页面仅在缓存仍可用时直接恢复；关闭缓存或结果被释放后可能需要重新处理。图片来源、语言或服务变化后不复用旧译图。
- 再次点击显示原图并暂停新任务；再点一次恢复译图并继续。当前可见页的结果可以直接切换，不重复请求；附近页面使用有数量和像素限制的缓存，远处被释放的页面可能需要重新处理。
- 失败页保留原图，其余页面可以继续；可用漫画按钮先切回原图、再开启以重试；未检测到文字的页保留原图并继续阅读。切到其他章节、关闭漫画连续翻译或插件总开关、离开网页后，会停止旧任务并恢复原图。普通图片开关不会关闭漫画会话。

漫画沿用图片翻译服务、原语言和目标语言，没有额外会员或张数限制；所选服务自身的额度与费用仍然适用。其他已登记网站或常见阅读路径会检测正文图片阅读器，只有检测到正文图片或已适配的画布才显示入口。**支持的网站** 可搜索 235 个清单名称及域名；登记表示可以检测阅读页，不代表所有章节已实测通过。WeebCentral、Dynasty 和 MangaDNA 使用专用正文规则。在 MangaPark，先从作品页打开可读章节，再点击漫画翻译。Champion Cross、Comic Ryu、Comic Growl、Rimacomiplus、Heros Web、YoungAnimal、YoungChampion 和 ComicWalker 的可读正文画布支持同一套连续翻译、暂停原文和翻页续译，原画布与翻页操作保持不变；读取失败时提供圈选入口。Comic Zenon、Comic Days、ComicGardo、Comic-Trail、Comic-action、Kurage Bunch、ShonenJumpPlus、tonarinoyj、Ichicomi 的画布阅读页及 YanMaga、Jumptoon、Televi-Kun Super Hero Comics、Comic Meteor（Kirapo）的画布或分片阅读页显示 **圈选漫画翻译**，点击后拖选可见漫画区域。需要启用圈选翻译；这种方式不提供滚动连续翻译。登录或受保护阅读器仍取决于网站实际展示的内容。有经验的用户可在 **支持的网站 → 添加其他漫画网站** 按精确域名、阅读路径和图片选择器增加适配。仅处理页面中可访问的图片，错误选择器不会中断网页；自定义规则不代表已经验证该网站。其他网站仍可用单张图片或圈选翻译。

Pixiv 只处理当前作品的正文图片；展开作品阅读器后会优先处理展开的页面，避免重复翻译背后的封面。扩展核对网页中的当前图片后，仅为自己读取该张 Pixiv CDN 图片临时附加站点来源，处理其防盗链要求；不会携带登录 Cookie 或改动网站自己的图片请求。该能力增加 `declarativeNetRequestWithHostAccess` 扩展权限，漫画本地模型链路用于浏览器扩展，油猴版本仍有能力限制。

漫画固定使用本地 PaddleOCR。浅色封闭气泡会单独放大识别，将相邻文字合成整段对白，再限制字号和换行；复杂背景上的原字形用本地 LaMa 模型局部修补。单张图片可选 Tesseract 或 PaddleOCR，仍保留自己的轻量界面和整图结果；圈选识别方式保持独立。LaMa 用于背景修补，不是文字识别模型，单图选择 PaddleOCR 不会额外加载 LaMa。小字、倾斜文字、艺术字体、人名以及背景修补仍可能有误，可以随时点击漫画入口切回原图核对；普通图片可打开 **文字 → 原文对照**。

漫画对白使用适度粗体；复杂背景上的原始大字保留标题层次与白色描边。换行将标点与相邻文字放在一起，末行过短时在原文字范围内平衡行宽。使用系统字体，无需额外下载字体；这些改动改善呈现，不保证每张图片都能准确识别与翻译。

正在处理的那张漫画会在可见图片边缘显示紧凑的阶段提示，完成或切回原图后消失；下载完成后单独显示初始化模型，有实际下载、识别或清除百分比时显示数值和进度条，等待翻译服务时只显示阶段，不估算总进度。提示不接收鼠标操作，不阻挡滚动。关闭装饰动画后，加载圈仍会转动；系统开启减少动态效果时使用静态提示。漫画模式不显示左下角“原图／文字”操作条或取消弹窗，使用漫画入口随时对照原图与译图。预合成只准备缓存，不撤下仍在阅读的译图。普通图片仍使用之前的轻量加载提示，取消按钮留在图片操作条，不移到中央卡片。

源语言明确选择 **Русский** 或 **한국어** 时，连续漫画使用已有的俄语／韩语与英语 OCR 语言包，继续使用漫画清字、排版和缓存。首次开始时会说明需要准备的资源；已下载的包直接复用。自动检测目前仍使用漫画专用模型，其字表不包含俄文或韩文，因此阅读这些语言的漫画时请明确选择原文语言。网站的界面语言不一定等于正文语言。

### 漫画资源下载

在 **图片/漫画翻译 → 识别资源与下载** 查看按用途区分的资源状态；展开 **下载与管理** 导入已下载文件或清理资源。PaddleOCR 识别模型约 30 MB；漫画首次处理复杂背景时另需约 197 MB 修补模型。只开启单图 PaddleOCR 时不显示漫画修补资源。通用 Tesseract 语言包在同一区域单独管理。下载和校验显示进度与已收到的容量，漫画按钮显示准备状态，不遮挡画面。

资源首次使用时自动准备，连接或文件校验失败时自动重试，无需选择下载来源。已完整下载并校验的文件会保留，取消或失败后重试只准备缺失的文件。正在下载的单个文件取消后需要重下。清除漫画模型不会删除普通 OCR 语言包或翻译配置。

已有配套模型文件时，点击 **导入已下载文件**，可一次选择多个文件。导入只接受指定文件名、完整容量和匹配的 SHA-256；文件留在浏览器本地，不上传。模型齐全后，识别和修补可离线运行，文字翻译服务仍需要自己的网络连接。

## 设置页预览与分区

图片与漫画设置在左侧展示固定英中示例，右侧选择识别方式或提前翻译数量；示例不运行 OCR，也不发送翻译请求。原语言和目标语言与网页翻译共用，图片与漫画共用此处选择的翻译服务。

**圈选翻译设置**、**入口与缓存**、**识别资源与下载** 和 **支持的网站** 直接展示；离线导入、资源清理和自定义网站等操作仍可按需展开。查看资源状态不会自动下载模型。

## 翻译一张图片

1. 确认 **图片翻译** 已开启，鼠标移到图片上停留约 0.6 秒，点击左下角的图标；也可以右键选择翻译图片。
2. 使用通用识别时，第一次使用某种语言按提示点击 **下载语言包并翻译**；使用 PaddleOCR 时，首次翻译准备其共享识别模型，已有资源直接复用。
3. 等待识别与翻译完成。想中途退出，点击 **取消**。
4. 完成后切换 **原图 / 翻译** 对照。点击 **文字** 打开独立阅读面板，选择 **原文对照** 核对识别结果，并一键复制译文或对照。小图片也能完整阅读长译文。

设置中的语言包列表优先展示当前原语言需要的资源、已下载项和进行中的任务；其他语言可展开查看。点击 **下载所需语言** 后，每个包单独显示等待、下载、完成或失败；下载中的包在名称下方显示进度条和百分比。离开设置页不会中断下载，重新打开可查看状态；部分失败时保留已完成项，只需重试缺失的包。移除语言包后，再次使用时需重新下载。

文字识别与文字翻译是两个步骤。使用本地翻译模型时，短词或混合语种可能影响语言自动检测，所选模型也可能只支持特定语言方向。失败提示会说明语言方向、模型下载、浏览器支持或超时等原因。点击 **调整本地模型** 可检查下载与模型选择；点击 **切换图片翻译服务** 可调整图片专用服务与原语言。修改后返回图片点击 **重试**，不会自动把本地文字改送在线服务。

翻译完成后，鼠标离开图片且键盘焦点不在控件中时，**原图／文字** 操作条会隐藏；回到图片即可再次使用。打开文字面板时仍保留操作入口。

点击图片打开网站的大图查看器时，被遮挡的缩略译图和文字面板会隐藏，避免悬浮在大图上。大图可以独立翻译；关闭查看器后，列表中的译图直接恢复，无需重新请求翻译。

文字识别与文字翻译是两个步骤。使用本地翻译模型时，短词或混合语种可能影响语言自动检测，所选模型也可能只支持特定语言方向。失败提示会说明语言方向、模型下载、浏览器支持或超时等原因。点击 **调整本地模型** 可检查下载与模型选择；点击 **切换图片翻译服务** 可调整图片专用服务与原语言。修改后返回图片点击 **重试**，不会自动把本地文字改送在线服务。

翻译完成后，鼠标离开图片且键盘焦点不在控件中时，**原图／文字** 操作条会隐藏；回到图片即可再次使用。打开文字面板时仍保留操作入口。

如果翻译连接意外中断，会自动重试一次，期间仍可取消。若仍然失败，点击 **重试**；扩展更新或重新加载后，需要刷新当前网页再试。

## 跨域图片

普通网站 CDN 上的公网 HTTPS 图片也可以翻译。网页无法直接读取像素时，扩展会核对当前选中的图片，再读取不带登录凭据的图片数据。取消、换图或离开页面后，旧请求不会继续覆盖图片。

需要登录凭据、跳转到其他地址、本地或内网来源的图片可能无法读取；可以尝试对可见文字使用[圈选翻译](/guide/area-translation)。图片文件超过 16 MiB、服务器拒绝访问或返回非图片内容时会显示具体原因。

## 源语言设置

在 **图片/漫画翻译** 顶部选择识别语言；这项设置与网页翻译、圈选翻译共用。Tesseract 语言包应与图片中的原语言匹配。自动检测默认准备简体中文、繁体中文、英文和日文；其他支持的语言需要先明确选择原语言，再下载对应语言包。

使用 Tesseract 时，如果确定图片是纯英文，选择 **English** 可减少识别等待；混合语种图片适合保留 **自动检测**。已完成的同图识别会复用结果；同时翻译同一张图片时，文字识别也会共享，一处取消不会中断其他正在使用的任务。第一次下载语言包仍需等待网络传输。

原语言为自动检测或日文时，日文语言包会同时识别横排和竖排文字；漫画气泡里的竖排文字按从右到左的列顺序合并成一段再翻译。

翻译服务与目标语言沿用当前设置。悬浮图标和右键入口可以在图片翻译设置中分别关闭。

</details>

## 太小、太糊，怎么办？

优先打开清晰原图。艺术字、复杂背景、表格以及日文以外的竖排文字更容易识别出错，注意核对人名、数字和单位。

译文太长时，在图片里可能显示得较小，点击 **文字** 看完整结果。空识别的小图片会自动换一种布局方式再识别一次；仍未识别到文字时，建议确认原语言或重新圈选清晰区域。背景修补可能留下痕迹，原图始终可以恢复。

只想看图里的一小块，试试[圈选翻译](/guide/area-translation)。无法读取的图片或受限制的页面可能不能处理。

<details class="guide-details">
<summary>入口显示与小图片</summary>

图片翻译识别网页图片中的文字，并在原图上显示译文。默认关闭，可在设置中按需开启。开启后，鼠标在图片上停留约 0.6 秒，左下角会显示淡色图标；移到图标上会变清晰，点击即可开始。

X 等网站可能由透明原图或透明链接接收鼠标，再用背景层显示图片；与原图同源、同尺寸的这些媒体入口不影响悬浮按钮。真正的查看器、弹窗或菜单遮住图片时，按钮与译层会暂时隐藏，关闭遮挡后恢复。

头像、常见图标、Logo、表情、视频封面和过小的图片会尽量跳过，减少浏览干扰。X／推特等网站的视频在尚未播放、只显示预览图时，也会根据播放器或封面标记跳过。小图即使被放大，也可能不会显示悬浮入口。如果需要翻译的图片没有出现图标，可以右键选择翻译图片，或打开清晰原图后再试。

图片与圈选在同一个设置页面中配置，保留独立开关与操作方式。展开 **识别资源与下载** 管理共享的 Tesseract 语言包及 PaddleOCR 资源。

</details>

## 图片会发送出去吗？

文字识别在浏览器本地完成，识别出的文字交给所选翻译服务。图片像素不会作为文本翻译请求上传。语言包首次下载需要网络，详见[数据与隐私](/guide/privacy)。
