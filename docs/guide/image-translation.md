# 图片翻译

图片翻译用于处理截图、漫画、扫描文档和网页图片中的文字。它的流程是“读取图片文字 → 整理识别结果 → 请求翻译服务”，因此比普通段落翻译更依赖图片质量和服务响应。

## 使用前准备

- 确认已经启用至少一个支持图片内容的翻译服务。
- 图片中的文字尽量清晰、完整，避免过度压缩或强烈背景纹理。
- 如果使用 AI 服务，确认所选模型支持视觉输入；纯文本模型无法直接理解图片。

## 操作步骤

1. 打开包含目标图片的网页。
2. 从 FluentRead 弹窗进入图片翻译功能。
3. 选择目标语言和翻译服务。
4. 上传图片或选择页面中的图片。
5. 等待识别和翻译完成，再检查专有名词与排版。

## 结果不准确时

优先更换更清晰的原图，或裁剪掉与文字无关的区域。对于表格、代码、竖排文字和艺术字体，建议把识别结果当作辅助阅读，并手动核对关键内容。

图片会按照当前服务的请求规则处理。使用第三方云端服务时，请先确认其隐私政策和数据处理方式；敏感截图更适合使用本地模型或不要上传。
