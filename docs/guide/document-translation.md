# 文档翻译

文档翻译支持导入本地文件、双语对照阅读、校订译文和下载结果。

<GuideVisual kind="document" />

## 打开文件

从扩展菜单进入 **文档翻译**，将文件拖入页面，或点击选择文件。

在线 PDF（例如 [Attention Is All You Need](https://arxiv.org/pdf/1706.03762)）可以直接打开扩展菜单，点击 **打开 PDF 阅读器** 或 **文档翻译**。也可以在文档首页粘贴 PDF 链接。浏览器自带 PDF 查看器限制内容脚本，流畅阅读会在自己的阅读页打开原文件，不修改原文。需要登录的下载地址若无法打开，请先下载再导入。

支持 PDF、ePub、Word（DOCX）、HTML、TXT、Markdown、JSON，以及 SRT、VTT、ASS、SSA、LRC 字幕文件。旧版 `.doc` 文件请先另存为 `.docx`。

还没有文件时，可展开 **没有文件？先用范例试试**，打开文章、字幕或语言文件范例。范例在本地导入，不会自动开始翻译；确认设置后可使用与真实文件相同的阅读、校订和下载流程。

## 翻译与对照阅读

1. 在顶部工具栏直接选择 **翻译服务** 和 **目标语言**（使用 AI 服务时还会出现模型）。源语言与术语库在左侧栏底部的 **源语言与术语库** 中调整。
2. 检查文件内容，点击 **开始翻译**。
3. 通过 **原文 / 双语 / 译文** 切换阅读方式。

窗口较窄时，工具栏按阅读和翻译操作分行，服务、目标语言与模型收进 **翻译设置** 弹窗；阅读、校订、翻译或暂停以及下载入口仍保留在页面上。

文件名下方同一行显示任务状态、已翻译段落数和百分比，翻译过程中会持续更新。

译文不必等全文结束：每译完一批就显示一批，并从你正在看的位置开始（PDF 的当前页、ePub 的当前章节、Word 的当前部分、字幕与 JSON 的当前页）。默认开启 **多段合并翻译**，支持的机器服务和 AI 服务会合并多个段落发送，并复用重复原文的译文，减少小请求。此开关仅用于当前文档，可在 **翻译设置** 中关闭；不会修改网页或全局多段翻译设置。开启下述篇章参考时按章节区分重复原文，并逐段执行。

HTML、ePub 和 Markdown 里带链接、加粗、斜体或行内代码的句子会作为一整句翻译：链接和强调保持在对应的词上，Markdown 的链接文字会翻译而地址、行内代码和网址原样保留。翻译服务丢失或破坏这些标记时，该结果不会显示或缓存；免费服务池会尝试其他线路，仍无法保留格式时会提示重试或切换服务。

Markdown 的标题级别、列表编号、容器指令和独立 HTML/组件标记保留在本地。免费服务池会检查行内格式及可确认的行内正文漏译；发现问题时自动尝试其他线路，避免下载后丢掉加粗、链接或代码的位置。专名、代码和用户词库指定的内容仍按原有规则保留。

文档正文里的网址、邮箱、`FluentRead` 一类代码式名称及 `GNMT+RL` 一类组合标识会原样保留。免费服务对技术名词的译法可能不同；格式检查和自动保护不能保证正文译意、完整性或完全没有重复。需要统一术语时，可选择适合文档的词库，并在校订页检查关键段落。

较长的文档可以暂停。暂停或请求失败后，已完成的内容会保留，继续翻译时处理剩余部分；更换服务或模型也会保留已有译文和校订。更换语言或术语设置后，需要按新设置重新翻译，页面会先提示。失败提示中的 **详情** 可展开查看服务返回的完整原因。

翻译完成后，主区域保留阅读、校订和下载。左侧栏可折叠：**文件** 页切换、添加或移除文档；PDF 以及带标题的 Markdown、HTML、ePub 和 Word 文档还有 **目录** 页，可按原文或译文显示章节并点击跳转；ePub 的全部章节都列在这里，当前章节下面是它的各级标题。Markdown、纯文本和 Word 在宽窗口里按段落左右对照，窗口较窄时译文排在原文下方；Word 里的表格仍按表格显示，译文在各自的单元格里。需要只看文档时点击 **专注阅读**，按 Esc 退出。

所有格式都支持在正文上使用触控板捏合放大、缩小，也可按住 Ctrl 滚动滚轮。双指平移照常滚动文档。点击正文后可用 **Ctrl/Cmd +**、**Ctrl/Cmd −** 调整缩放，**Ctrl/Cmd 0** 恢复；工具栏提供相同操作。非 PDF 文档可在 50%–300% 之间缩放，点击百分比恢复 100%；PDF 恢复适合宽度，原版排版缩放时尽量保持指针下的页面位置。缩放只影响阅读预览，校订输入和下载文件使用原有排版。

PDF 的缩放和显示方式菜单也可以用键盘操作：用 Tab 移动到选项，按 Enter 或空格选择；按 Esc 关闭并返回菜单按钮。

Markdown 围栏代码块保持原文，包括引用和列表中的围栏；阅读预览会将它们作为代码展示。纯文本里按固定宽度折行的段落会合成一段翻译，标题、列表和各自成句的行仍逐行处理。JSON 保留原有结构和非文本值，版本号、网址、颜色值和带数字的标识符这类给程序看的字符串也原样保留、不送去翻译，嵌套超过 1000 层时会提示无法处理。

### 篇章参考

使用支持通用提示词的 AI 服务并开启 **AI 精翻** 时，文档翻译会参考当前章节的原文定义、邻近段落和已完成译文。同一章节里的重复原文仍可复用，章节之间的同名缩写分别处理；PDF 页码作为来源位置，标题才表示章节。当前阅读会话中手动编辑的译法标为用户确认，优先于机器参考，用户术语库仍有最高优先级。历史译文不自动视为用户确认。

该模式按阅读优先位置逐段执行，让后续请求拿到已完成译文，因此可能比默认并发模式更慢；拆开跨章节的重复原文也可能增加正常翻译次数。篇章状态自身不额外调用模型，不跨文档保存。换文件、重译、正文重建或取消后，旧状态不会继续写入。容量上限为 256 个原文块、64,000 个原文字符和 64 对译文；参考随当前章节移动，远处未采集的依据可能缺失，不保证模型消除所有歧义。

## 保存材料并继续阅读

在阅读工具栏点击 **加入学习材料**，可以把这份文档与收藏、提问和笔记放在同一份材料中；已保存时按钮变为 **更新学习位置**。PDF 会记录当前可见段落，继续滚动阅读后也会更新位置。在原文或译文中收藏表达时，材料保留对应的完整原文位置。

在学习中心打开材料并选择继续阅读，会回到保存的段落。自动定位期间主动滚动或使用阅读导航，会停止自动定位并按你的当前位置继续。原文被重新解析后，如果无法确认原段落，插件会保留旧定位并提示你找到原文后点击 **更新学习位置**，不会跳到另一页的相同句子。较早保存的材料可能只能恢复页码或章节，进入后请核对位置；当前页面尚未加载完成或没有可见文字时，等待加载或滚动到文字后再保存。

本地文件已被清理时，重新选择原文件即可继续；同名但内容不同的文件不会覆盖原材料。材料与定位保存在本机浏览器中。

## 校订与下载

点击 **校订译文**，搜索想修改的句子，或筛选尚未翻译的片段，直接编辑译文。修改会用于预览和下载。

点击 **下载文件**，可直接 **下载原文**：本地导入和链接打开的文件都按原文件名、原格式保存，不包含翻译或校订；无需先翻译，生成译文文件时也能保存原文。原文使用已经打开的文件，不会再次请求链接。

翻译结果的下载方式默认跟随当前的双语或译文阅读方式；阅读原文时保留上次下载选择。可在弹窗中再次选择双语或仅译文，核对输出文件名和内容预览。二进制文件展示文字摘录，实际下载仍保留原格式。

ePub 下载保留章节顺序、链接、图片和原有样式；双语章节保持标准 XHTML 格式。ePub、DOCX 和批量 ZIP 下载会显示打包百分比，可以取消后再次下载，译文和校订会保留。大型 JSON 的下载预览使用文字摘录，实际文件仍包含完整 JSON 结构；文本格式只生成弹窗需要的预览片段。PDF 译文随翻译进度显示；其他格式的阅读预览在暂停或完成时更新，减少长文档的重复处理。

字幕选择 **仅译文** 时会替换字幕文字，保留序号、时间轴和格式标签；选择 **双语对照** 则在同一时间段内保留原文与译文。校订会写入下载文件。尚未完成时，需要明确确认下载当前结果，缺少译文或已清空译文的位置保留原文。更改设置不会自动重译，下载仍使用当前保留的结果。

::: tip 刷新不会丢失进度
文档、译文和校订会保存在本机浏览器里：刷新后回到正在阅读的文档，首页的 **最近翻译** 可以一键恢复，也可以逐条移除或清空。需要带走或分享时请下载文件。

识别到明确接续关系的相邻页正文还提供 **跨页上下文**，可在同一窗口查阅上下段原文与译文；不会自动删改断词连字符或合并校订。

PDF 重新解析后会更新文字位置并恢复已有校订。恢复要求原文逐字一致；重复句子优先按原生页与位置匹配，不按出现次序猜测。若某段原文的结构发生变化、无法安全回填，旧内容会保留在 **校订译文 → 保留的旧校订** 中，可展开查阅和复制。
:::

## PDF 有哪些限制？

原版排版中的长译文若放不下，会显示可读的一行预览；点击全文入口可查看完整内容。下载的 PDF 会保留完整批注，并在对应原页后添加译文续页。预览中的一行不是完整译文。

在线和本地导入的 PDF 共用阅读器。原页文字可以选择、复制，并按你的划词设置显示翻译图标、直接弹出卡片或使用快捷键；划词使用设置中的划词翻译服务，整篇翻译使用文档翻译服务。可连续阅读、输入页码跳转或调整缩放，无需先翻译整份文件。

阅读器优先渲染可见页，最多保留五页的画布与文字层，离屏页会释放并在返回时重新生成。缩放保留当前页位置；导入显示下载字节或解析页数，并支持取消后重试。

论文、报告、幻灯片导出的 PDF、笔记和文字处理软件导出的文档都按各自的版面分段：幻灯片的内容框和标题色带里的文字照常翻译，1.5 到 2 倍行距的正文仍按整段翻译。单个 PDF 最大 50 MB，其他格式最大 10 MB。

自动识别的数学字形和运算符保留原字符，术语库中指定的译法优先。普通字母变量、领域用词和复杂论证仍可能需要校订；公式完整并不代表正文译意全部正确。

没有文字层的扫描版 PDF 也可以翻译：点击 **开始翻译** 后会先从当前页起逐页识别文字并显示进度，随后按同样的版面方式翻译；可以随时暂停。识别使用图片翻译的识别语言包，缺少时会自动下载，请先选择正确的源语言。扫描页上的文字不能选中复制；文字 PDF 里夹着的扫描页和旋转的扫描页同样会识别并按摆正后的方向排版，空白页不会。

PDF 默认使用 **原版排版** 左右对照：译文按原文段落的位置和字号放回页面，逐段到达逐段显示，等待中的段落显示你在界面风格里选择的加载样式；公式、插图和纯数字的表格单元格保持原样，表头、文字单元格和图表题注会翻译。译文可以用鼠标划选，再用 Ctrl/Cmd+C 复制。放不下的长译文悬停即可展开，拖选和选区保留期间会保持展开；也可点击段落角上的展开按钮，或用 Tab 聚焦后按 Enter，打开可选择复制的 **完整段落** 对照，按 Esc 返回原段落。悬停译文会高亮对应原文（可在 **译文样式** 中关闭）。也可以切换 **重排阅读**，按完整段落和固定字号阅读。工具栏还提供 **搜索**（同时匹配原文与译文）和 **译文样式**（字号、字体）。

翻译从正在阅读的页开始，持续显示已翻译段落数、总数、百分比和进度条。只有已完成并显示的译文增加进度，发送请求和自动重试不会增加；最后一段返回后，任务收取完所有结果才显示 100%。扫描 PDF 的文字识别先显示页数进度，识别完成后再显示段落翻译进度。

服务暂时不可用时自动重试，累计最多等待两分钟，并显示等待状态和原因。无法继续时会保留成功译文和人工校订，工具栏提供 **重试**，简短原因旁可 **更换服务**；需要排查时展开 **详情** 查看完整错误。已发出的其他请求若成功仍会保存；不想继续等待时，可以暂停并切换服务。切换服务或模型后点击继续翻译，只处理尚未完成的段落，已有进度和译文保留。修改语言或术语设置会另行提示确认重新翻译，以免同一文档混入不同目标语言。

下载 PDF 默认保留原版排版：双语版每张原版页左侧为原文、右侧为同一原文页的译文；仅译文版保留对应的译文页。原版页的相对顺序保持不变。译文及未替换的原文文字带有可搜索、可复制的 Unicode 文字层，公式和图表保持原图外观。原位放不下的长段落会保留 PDF 批注，并在该原版页后附上完整可见续页，标明原页码和段落；续页底部可点击返回对应原版页，PDF 页标签也保留原页与续页关系。因此实际页数可能多于原稿，下载窗口显示原版页数下限和生成进度。可见文字续页优先使用真实字体；字体离线或缺字时用本机 Canvas 保持外观，并保留同样的搜索复制层。普通原版页的文字层无需额外下载字体。点击 **取消生成** 会保留译文和校订，可以重试；阅读器只挂载附近页面，导出逐页编码并释放画布。

单份文档在 **重排阅读** 下下载时，译文以固定字号自动续页，中文和中英混合译文可直接选择、复制和搜索；双语版在原页后接完整译文。能放入单页的公式和插图以原图整块保留，剩余空间不足时移到下一页。行内数学字形可能与原稿字体不同，需要精确保留字形时请使用 **原版排版**。首次重排导出需要联网下载约 5 MB 的字体，下载失败可再次点击下载重试；校验并缓存成功后，后续导出复用本机字体，也可离线生成。字体请求不包含文档、译文或服务密钥。浏览器导出遇到字体缺字或字体离线时，可用本机 Canvas 与 Unicode 文字层保留可见内容；罕见字符外观取决于本机可用字体。批量下载使用默认原版排版。

## 文件会上传吗？

文件在浏览器中解析，待译文字会发送给你选择的翻译服务。使用云端翻译时，相关文字会离开本机；详见[数据与隐私](/guide/privacy)。

## 在 Obsidian 中翻译

流畅阅读提供[实验性 Obsidian 桌面插件](https://github.com/FluentRead/FluentRead/tree/main/integrations/obsidian)。按照插件目录中的说明构建并安装后，可从命令面板或文件右键菜单翻译 Markdown 笔记和带文字层的 PDF。译文会作为相邻的双语 Markdown 笔记保存并分栏打开，原文件不会被覆盖。Obsidian 插件目前使用微软翻译；待译文字会发送到该服务。PDF 译文按页排列，不保留原 PDF 版式。

## 批量翻译

可一次选择或拖入多个文件，也可在左侧栏 **文件** 页点击 **添加文件**，保留已有文件和译文；新添加的文件会成为当前文档。确认翻译服务和目标语言后，点击 **翻译剩余文件**，按顺序处理尚未完成的文档。

每份文件独立显示进度。导入或翻译失败不影响其他文件；点击 **暂停全部** 保留已完成片段，再次开始时继续剩余内容。设置更改后，已有部分译文的文件需要逐份确认重新翻译，避免覆盖校订。

任务停止后，点击队列中的文件即可阅读、校订或单独下载。选择双语或仅译文，再点击 **下载已完成文件（ZIP）**，打包所有完成的文档；未完成的文件不包含在压缩包中。同名文件放在不同编号目录中。切换文件会保留当前结果，移除未下载的译文会先提示。

文件和译文保存在本机浏览器，可从首页的 **最近翻译** 恢复；需要带走时请下载。
