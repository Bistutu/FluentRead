# 功能概览

本页介绍流畅阅读的主要功能及使用方法。首次使用请阅读[快速开始](/guide/getting-started)。

<summary>页面翻译</summary>

## 页面翻译

在原网页中按段落显示译文。点击扩展菜单中 **在此网站禁用扩展** 按钮右边的显示模式图标，可在双语对照与仅译文之间切换，选择会自动保存；也能随时恢复原文。Google 翻译只支持双语。

[查看操作指南](/guide/webpage-translation)

<summary>翻译中心：多服务对比</summary>

## 翻译中心：多服务对比

在 **设置中心 → 工具与学习 → 翻译中心** 中输入或粘贴原文，选择语言后点击 **开始翻译**，也可以按 Mac 的 **⌘ + Enter** 或其他系统的 **Ctrl + Enter**。

[查看操作指南](/guide/translation-center)

</details>

<details class="guide-details">
<summary>局部翻译</summary>

## 局部翻译

只想读网页中的一部分时，例如 GitHub 项目的 README、文章正文或某个评论区，不必翻译整页。

进入局部翻译后，移动鼠标预览，单击锁定一个区域；也可按住鼠标左键划过多个段落，经过的区域会逐块高亮，松开后锁定选择；用 **↑/↓** 或锁定后的工具条调整范围，再确认翻译或恢复原文。预览和锁定状态下都可按 **Enter** 确认，按 **Esc** 或右键退出。

[查看操作指南](/guide/webpage-translation)

</details>

<details class="guide-details">
<summary>英文单词查词</summary>

## 英文单词查词

划词词卡内置 3,000 个常用英文词条，首次查词无需下载额外资源。

[查看操作指南](/guide/deepseek-harness)

本地命中的词典释义直接显示，辅助释义随后补充，普通译文也会独立显示。在线查词最多等待 2.5 秒；等待期间以一行提示显示进度。未查到条目时会提醒检查拼写，并说明名称或新词也可能未收录；网络不可用时可点击“重查词典”，已有普通译文会保留。词性与句法视图按有意义的句中成分分组，片段下方显示当前界面语言的作用与词性，例如“主语 · 名词短语”“后置定语 · 不定式短语”。进入读懂等学习动作时先呈现解读结果；在“更多操作”中选择“查看原文”可展开完整原文和普通译文，点击“返回当前阅读”收起对照。

</details>

## 双语逐句高亮

开启逐句高亮后，指向原文或译文的一句话，同步强调另一侧的对应句子。适合定位长段落中的难句。

<details class="guide-details">
<summary>选中即译</summary>

## 选中即译

先在扩展菜单的 **划词翻译** 中开启双语显示，再选中词语、句子或段落，点击附近的流畅阅读图标查看译文。

句子和段落先显示译文，完整原文保留在下方，向下滚动即可对照。卡片的内容导航保持一行，窄卡片中可横向滚动或用 Tab 键访问后面的学习动作。拖动、缩放、切换学习内容和流式回答都会保留手动设置的位置与尺寸。

学习短回答按内容收拢，长回答在卡片内滚动；未播放时音频栏不占正文空间。更多操作在回答旁，追问在回答之后，可滚动或用 Tab 键访问。切换界面语言不会改写原文和译文内容。

[查看操作指南](/guide/deepseek-harness)

</details>

<details class="guide-details">
<summary>恢复、样式和主题</summary>

## 恢复、样式和主题

在设置中选择译文样式、界面主题和菜单栏布局。

“界面与弹窗”提供完整弹窗预览，切换风格即可查看顶部操作、翻译控制、功能卡片和底部信息栏的外观。除默认、简约、紧凑和高对比外，还有十套取自中国传统色的风格——青花、朱砂、水墨、竹青、藕荷、缃色、青绿、月白、玄青、乌金；它们全部使用平涂色，其中玄青与乌金始终为深色。菜单栏布局里的预览与真实菜单栏是同一套界面；编辑菜单栏布局时，点击卡片右上角的 × 移除栏目，可在下方通过“添加”恢复。界面字体采用紧凑卡片，标题与描述直接展示各字体的真实样式，无需先下载完整字体，离线也可预览。直接选择即可使用或下载，已下载字体可查看并清除缓存。

[查看操作指南](/config/)

### 请求限制

服务提示请求过于频繁时，降低并发或请求速率。具体操作见[请求限制](/config/#请求限制)。
