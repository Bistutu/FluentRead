# 功能总览

FluentRead 的功能可以拆成三层：在页面中阅读、在局部内容中阅读，以及按自己的服务和习惯进行配置。

## 页面翻译

使用“翻译页面”处理当前网页，译文会作为独立的双语内容插入原文附近。原文仍然存在，因此你可以对照阅读，也可以随时恢复。

<img class="doc-screenshot" src="/screenshots/translation.png" alt="Bilingual page translation" />

适合：新闻、博客、技术文章、在线文档和长篇资料。

## 选区翻译与悬浮翻译

不需要整页翻译时，直接选中句子、段落或术语即可。选区翻译更适合快速查词、核对句意和处理页面中的少量外语内容。

可用的触发方式、快捷键和显示行为会受到当前浏览器及页面结构影响；遇到页面不响应时，优先尝试手动选择文本或使用弹窗按钮。设置页的“交互与快捷键”中可以调整“悬浮翻译延迟”（默认 50ms）；如果 `Ctrl+C` 等组合键容易误触翻译，可以适当调高等待时间。

在弹窗的“划词翻译”卡片中还可以单独开启“圈选翻译”。开启后按住 `Shift + Z` 拖拽页面区域，适合翻译图片、视频画面、漫画气泡或无法直接选中的文字；释放鼠标后，FluentRead 会通过后台截图和 Offscreen OCR 处理当前可见区域，并把结果覆盖在原区域上。截图只在本次识别期间保存在内存中，不会写入磁盘；按 `Esc` 或结果右上角的关闭按钮即可移除覆盖层。首次使用图片识别时，需要先在图片翻译设置中下载对应的 OCR 语言包。

划词翻译结果旁的扬声器按钮提供免费 Edge TTS 朗读。默认会按当前语言依次尝试多个音色；也可以在同一张“划词翻译”设置卡片中选择多个语言音色，按选择顺序作为回退链。播放由扩展自己的 Offscreen 文档承接，页面有严格媒体 CSP 时仍可继续朗读；Edge TTS 全部不可用时，再回退到浏览器语音和 Google TTS。

选中一个英文单词时，划词卡片会切换为学习模式：显示单词、音标、可播放的词典发音、词性、英文释义、例句和当前目标语言译文。词典只发送被选中的单词，不发送页面地址或上下文；结果来自多个公开/免费数据源，并在扩展后台按顺序降级。外部服务不可用时，仍会保留普通划词翻译和 Edge TTS / 浏览器语音回退。

## 图片翻译

对截图、漫画、扫描资料和图片中的文字进行识别，再请求已配置的翻译服务。图片翻译通常比普通文本需要更多处理时间，准确率也会受到字体、清晰度、背景和语言影响。

详细流程见[图片翻译](/guide/image-translation)。

## 多种翻译服务

FluentRead 将翻译服务作为可替换的适配器。你可以按场景选择：

| 类型 | 适合场景 | 需要注意 |
| --- | --- | --- |
| 免费服务 | 低门槛体验、临时阅读 | 可用性和速度取决于公共服务状态 |
| Microsoft、Google、DeepL | 稳定的云端翻译 | 需要自行准备凭据，并遵守服务条款 |
| OpenAI 兼容 API | 希望使用大模型理解上下文 | 成本、延迟和输出稳定性取决于模型 |
| Ollama | 希望在本机处理内容 | 需要本地模型、足够的硬件和正确的 CORS 配置 |

配置方法请看[翻译服务](/config/translation-engines)。

## 可恢复、可重译

翻译结果不会永久覆盖原文。你可以恢复当前页面，再修改服务、语言或样式后重新翻译。对于长页面，建议先用小段落验证服务配置，再开始整页处理。

### YouTube 视频字幕翻译（Beta 测试）
视频字幕翻译默认关闭。在 YouTube 播放器右侧控制栏会显示 FluentRead 图标入口，播放器菜单顶部显示中文品牌“流畅阅读”；点击后可查看“开启字幕翻译”的勾选状态、当前视频翻译服务和视频设置入口。开启后，FluentRead 会通过双语字幕面板显示译文和原文：原生字幕可见时面板会避开原生字幕并显示在其上方，逐词合并为整段原文时则固定在播放器底部安全区上方；面板带半透明深色背景、柔和阴影，不会因 YouTube 原字幕重绘或逐词宽度变化而上下跳动。

播放器菜单还支持“双语 / 仅译文 / 仅原文”三种显示模式、独立的“显示字幕”开关和“下载字幕”操作。下载会优先使用 YouTube 的 timedtext 字幕事件生成带时间轴的 `.srt` 文件；如果视频没有打开原生字幕或 YouTube 没有返回完整轨道，菜单会提示暂不可用，而不会把当前屏幕的一行字幕冒充完整文件。它不上传音频，也不改变播放器时间轴；如果视频没有打开原生字幕，翻译入口仍会显示，但不会凭空生成字幕。

视频翻译服务与网页文本翻译服务独立配置：可以在“通用设置”或弹窗的“视频字幕 Beta 测试”卡片中单独选择机器翻译或 AI 服务，并调整 FluentRead 字幕字号。视频默认使用微软翻译，也可以切换到 DeepLX、OpenAI、Gemini 等服务；机器翻译会提前约 10 秒预取，AI 服务会提前约 30 秒预取。原生字幕逐词写入时，FluentRead 会先按 timedtext 时间轴合并连续短词 cue，再复用完整 cue 的一次翻译，并在播放器中用整段原文覆盖逐词 DOM，避免长句一直等不到停顿；播放器时间轴进入下一条 cue 后，即使 YouTube 原生字幕 DOM 暂时落后，也会优先显示当前 cue。字幕面板只包住原文和译文并保留少量内边距，不再铺满播放器宽度。站点一次性给出完整句时直接显示整句，不人为拖慢播放。若尚未拿到完整时间轴则回退到字幕出现后的实时翻译。完整设置中的“视频字幕 Beta 测试”页面可以关闭该功能；当前版本仅处理 YouTube 的 `/watch` 和 `/shorts` 页面。

## 操作方式

## 阅读样式与主题

设置页提供主题、译文样式、字号和相关显示选项。建议先从默认样式开始，再根据网页背景选择浅色、深色或更低对比度的方案。

<img class="doc-screenshot" src="/screenshots/settings-general.png" alt="FluentRead general settings" />

## 缓存与服务管理

启用缓存后，重复请求相同内容时可以减少等待和服务调用。缓存并不等同于永久存档；如果页面内容发生变化，建议恢复原文后重新翻译。

服务管理页会集中展示可用引擎及其配置状态：

<img class="doc-screenshot" src="/screenshots/settings-services.png" alt="FluentRead translation service settings" />

## 快捷键

常用操作可以绑定浏览器快捷键，包括翻译页面、恢复原文、翻译选区等。不同浏览器对扩展快捷键的管理方式不同，具体配置步骤见[自定义快捷键](/guide/custom-hotkey)。
