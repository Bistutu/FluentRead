# 功能总览

FluentRead 的功能可以拆成三层：在页面中阅读、在局部内容中阅读，以及按自己的服务和习惯进行配置。

## 页面翻译

使用“翻译页面”处理当前网页，译文会作为独立的双语内容插入原文附近。原文仍然存在，因此你可以对照阅读，也可以随时恢复。

<img class="doc-screenshot" src="/screenshots/translation.png" alt="Bilingual page translation" />

适合：新闻、博客、技术文章、在线文档和长篇资料。

## 选区翻译与悬浮翻译

不需要整页翻译时，直接选中句子、段落或术语即可。选区翻译更适合快速查词、核对句意和处理页面中的少量外语内容。

可用的触发方式、快捷键和显示行为会受到当前浏览器及页面结构影响；遇到页面不响应时，优先尝试手动选择文本或使用弹窗按钮。

在弹窗的“划词翻译”卡片中还可以单独开启“圈选翻译”。开启后按住 `Shift + Z` 拖拽页面区域，适合翻译图片、视频画面、漫画气泡或无法直接选中的文字；释放鼠标后，FluentRead 会通过后台截图和 Offscreen OCR 处理当前可见区域，并把结果覆盖在原区域上。截图只在本次识别期间保存在内存中，不会写入磁盘；按 `Esc` 或结果右上角的关闭按钮即可移除覆盖层。首次使用图片识别时，需要先在图片翻译设置中下载对应的 OCR 语言包。

## 图片翻译

对截图、漫画、扫描资料和图片中的文字进行识别，再请求已配置的翻译服务。图片翻译通常比普通文本需要更多处理时间，准确率也会受到字体、清晰度、背景和语言影响。

详细流程见[图片翻译](/guide/image-translation)。

## 多种翻译服务

FluentRead 将翻译服务作为可替换的适配器。你可以按场景选择：

| 类型 | 适合场景 | 需要注意 |
| --- | --- | --- |
| 免费服务 | 低门槛体验、临时阅读 | 可用性和速度取决于公共服务状态 |
| Microsoft、Google、DeepL | 稳定的云端翻译 | 需要自行准备凭据，并遵守服务条款 |
| OpenAI 兼容 API | 希望使用大模型理解上下文 | 成本、延迟和输出稳定性取决于模型 |
| Ollama | 希望在本机处理内容 | 需要本地模型、足够的硬件和正确的 CORS 配置 |

配置方法请看[翻译服务](/config/translation-engines)。

## 可恢复、可重译

翻译结果不会永久覆盖原文。你可以恢复当前页面，再修改服务、语言或样式后重新翻译。对于长页面，建议先用小段落验证服务配置，再开始整页处理。

### YouTube / X 视频字幕翻译（Beta 测试）
视频字幕翻译默认关闭。在 YouTube 播放器或 X status 视频播放器旁会显示 FluentRead 图标入口。YouTube / X 已提供原生字幕时，FluentRead 会复用字幕轨道或页面已经渲染的字幕文本，在播放器中显示双语译文；不改变视频时间轴。字幕菜单支持“双语 / 仅译文 / 仅原文”、独立的“显示字幕”和“下载字幕”。

X 没有原生字幕时，菜单会显示“请求 AI 字幕”。只有用户主动点击后，扩展才会用 `MediaRecorder` 从当前 X 视频的音轨生成约 5 秒分片，交给扩展 offscreen 页面内缓存的 Whisper WASM 模型识别，再把返回的文字按时间轴交给同一套翻译和渐进显示逻辑。视频设置中可选择本地 Tiny 或 Base 模型；模型首次使用时从 ModelScope 下载并缓存，识别音频不会上传到云端，也不需要 Python、Docker 或额外本地服务。音频不会在未点击请求前采集。

视频翻译服务与网页文本翻译服务独立配置，可以在“通用设置”或弹窗的视频字幕卡片中选择字幕译文服务、本地 Whisper 模型和字幕字号。原生字幕的完整 cue 会提前预取并缓存；如果站点只给出逐词或局部文本，则回退到稳定后实时翻译。完整设置中的“视频字幕 Beta 测试”页面可以关闭该功能；当前处理 YouTube 的 `/watch`、`/shorts` 和 X / Twitter 的 `/status/` 视频页。

## 操作方式

## 阅读样式与主题

设置页提供主题、译文样式、字号和相关显示选项。建议先从默认样式开始，再根据网页背景选择浅色、深色或更低对比度的方案。

<img class="doc-screenshot" src="/screenshots/settings-general.png" alt="FluentRead general settings" />

## 缓存与服务管理

启用缓存后，重复请求相同内容时可以减少等待和服务调用。缓存并不等同于永久存档；如果页面内容发生变化，建议恢复原文后重新翻译。

服务管理页会集中展示可用引擎及其配置状态：

<img class="doc-screenshot" src="/screenshots/settings-services.png" alt="FluentRead translation service settings" />

## 快捷键

常用操作可以绑定浏览器快捷键，包括翻译页面、恢复原文、翻译选区等。不同浏览器对扩展快捷键的管理方式不同，具体配置步骤见[自定义快捷键](/guide/custom-hotkey)。
