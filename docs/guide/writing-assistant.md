# 写作助手

在 Gmail 和 GitHub 的回复编辑器旁起草回复，或完善已有草稿。检查结果后再插入，由你决定是否发送。

<GuideVisual kind="writing" />

## 开始前

进入 **设置 → 写作助手**，开启功能，选择兼容的 AI 服务与模型。未填写连接信息时，先在[翻译服务](/config/translation-engines)中配置。

可以选择正文和对照译文的语言，并设置篇幅、风格、语气和角色；这些选项也可在写作时临时调整。

## 起草一条回复

1. 在支持的 Gmail 或 GitHub 页面打开回复编辑器。
2. 点击编辑器操作区旁的写作入口。
3. 已有草稿会进入完善流程；空草稿有讨论上下文时会开始起草。新邮件没有参考内容时，先填写收件人、目的和要点，再点击生成。
4. 检查草稿，必要时补充要求并调整。
5. 点击 **插入回复** 放回当前编辑器，或 **复制回复** 后自行粘贴。

插入后仍需你在原网页中发送。写作助手不会自动发送邮件或评论。

点击写作面板外的页面可暂时收起，再点同一编辑器旁的写作入口，会恢复本次草稿、生成结果和正在查看的内容。收起时会停止尚未完成的生成，保留已生成的正文。若原编辑器已被修改、切换到其他编辑器或跳转到其他页面，下次打开会重新读取当前内容。

## 完善已有草稿

先在回复框里写下内容，再打开写作助手。保留你的原意，按需要调整语言、长度和语气。需要重新起草时，可修改参考内容再生成。

写作期间如果原编辑器内容发生变化，先核对当前草稿，再决定插入，避免覆盖新输入。

</details>

<details class="guide-details">
<summary>调整或关闭入口</summary>

## 调整或关闭入口

写作入口旁的菜单可以关闭本次入口、在当前网站禁用，或永久关闭功能。被禁用的网站可以从 **设置 → 写作助手** 中恢复。关闭不会删除已保存的服务与风格偏好。

</details>

## 数据去向

主动生成或调整草稿时，必要的参考文字、草稿和指令发送给你选择的 AI 服务。插入 Gmail 时会使用纯文本。请在发送前核对人名、事实和语气。

<details class="guide-details">
<summary>插入双语回复</summary>

## 插入双语回复

选择输出语言，再选择与它不同的对照语言。先核对正文下方的对照译文。**插入回复** 只插入正文；旁边菜单还提供 **插入双语回复**，把正文和对照译文依次插入。只有与当前正文对应的译文完整生成后才能使用。

插入 GitHub 时保留 Markdown 格式，插入 Gmail 时使用纯文本。原草稿有复杂格式或原编辑器已变化时，先复制回复，再自行粘贴。

</details>

<details class="guide-details">
<summary>参考内容与停止生成</summary>

## 参考内容与停止生成

**参考内容** 展示当前编辑器的草稿，以及可见的讨论或邮件上下文。生成前先核对；可选学习记忆沿用已保存的开关，无痕窗口不读取。

点击停止、关闭卡片或离开页面都会取消当前请求，已有正文保留。草稿与参考内容仅在本页会话中保留；写作请求与允许使用的学习记忆发送给所选 AI 服务。

</details>
