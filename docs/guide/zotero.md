# Zotero 文献翻译

流畅阅读提供实验性的 Zotero 桌面插件，可直接翻译文献库中的 PDF，阅读时翻译选中文字，并把译文保存为同一文献下的新附件或双语笔记。兼容清单以 Zotero 7–10 为目标，Zotero 7 兼容性尚未单独实测。

## 安装

此插件与浏览器扩展分别安装、分别配置。目前需要从源码构建：在 FluentRead 仓库根目录运行 `pnpm build:zotero`，得到 `integrations/zotero/dist/fluentread-zotero.xpi`。

在 Zotero 中打开 **工具 → 插件**，点击齿轮菜单，选择 **从文件安装插件**，再选择 XPI。插件尚未上架 Zotero 插件目录。

已在 macOS 的 Zotero 10.0.6 独立测试资料库中验证全文翻译、中文 PDF 回存、双语笔记和任务恢复；全文流程使用受控翻译服务，另以固定公开句子验证了微软翻译的真实中文响应。Zotero 7–9、Windows/Linux 和整篇论文的真实服务语义质量尚未完成实测，建议先在测试资料库使用。

当前为本地测试包，尚未发布到自动更新渠道。

## 配置翻译

打开流畅阅读工作台，选择源语言、目标语言和服务。默认自动识别原文并翻译为简体中文。

- **微软翻译**：使用流畅阅读现有的微软翻译服务，无需填写模型密钥。
- **OpenAI 兼容服务**：填写 Chat Completions 接口地址、模型与 API Key。远程接口使用 HTTPS，本机模型可用回环 HTTP 地址。
- **术语要求**：填写当前文献需要统一使用的译法。
- **输出**：选择双语或仅译文 PDF，也可设置完成后是否自动打开。

此插件独立保存配置，不读取或同步浏览器扩展的密钥。

## 翻译与继续阅读

在 Zotero 文献库选择一个或多个有本地 PDF 的文献，也可以直接选择 PDF 附件，然后从流畅阅读菜单加入翻译队列。

工作台显示每份文献的进度。多个文件依次处理；暂停保留已有译文，继续时处理剩余片段。任务失败后可以重试。关闭或停用插件后，未完成任务恢复为暂停，点击继续才会再次发送翻译请求。修改源语言、目标语言或服务后，新任务使用新设置；已有任务保留创建时的设置。

继续前会核对附件身份和文件内容。原 PDF 已改变时，需要新建任务，避免旧译文混入新文档。

翻译完成后，译文 PDF 作为新附件关联到原文献，原文件保留。独立 PDF 的结果保留在原文献库和分类中。任务操作还可将原文和译文按页保存为双语笔记。清理任务记录不会删除已经生成的 PDF 或笔记。

在 Zotero PDF 阅读器中选中文字，可通过流畅阅读的选区入口获得译文。该入口与文档翻译使用插件中选择的服务和语言。

## 文件与数据

当前支持带文字层的 PDF。扫描件需先添加 OCR 文字层；当前插件不内置扫描件 OCR，也不提供 EPUB、Zotero 网页版或移动端适配。译文 PDF 的排版和页数可能不同于原稿，原文件上的高亮和批注不会自动迁移到译文。

PDF 在本地解析和生成。开始翻译后，待译文字和必要的翻译提示发送到所选翻译服务，术语按你的词表处理。整份 PDF 不会上传到 FluentRead 云端。插件不收集遥测。

配置、任务和译文进度保存在当前 Zotero 配置目录的 `fluentread/` 中；API Key 在独立的本地 `credentials.json` 文件中保存，不进入任务记录或笔记。这个文件不属于加密密钥库。

PDF.js 运行资源随安装包提供。首次导出可能下载约 5 MB 的开放字体，校验长度与 SHA-256 后保存在本机字体缓存中，后续导出复用；下载请求不包含文献文字、译文或密钥。

只读文献库无法回存译文；找不到 PDF 时，请先在 Zotero 中下载附件或重新定位文件。

源码、构建方式和实现边界见 [Zotero 插件目录](https://github.com/Bistutu/FluentRead/tree/main/integrations/zotero)。
