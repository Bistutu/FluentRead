# 已观察 AR/FR 残留译文的共享门禁

中英专用的有道网页、金山词霸免费线路在源语言为自动检测时，先用现有语言识别检查解码后的每个正文槽。可信识别为其他语言时不发 HTTP 请求，以既有请求失败分类交给免费池换线，不冷却线路或修改免费服务顺序。短名称、技术词和不可信猜测仍保守处理；显式语言方向保留原约束。

中文目标的共享响应校验补足两类长正文：阿拉伯正文大量残留（包括丢失空格），以及只替换少量汉字、仍保留大量 Latin 原词的结果。判定同时要求可信外语原文及足够正文证据；汉字比例本身不能决定拒绝。中文解释内的成对长引文、中文主体、短名称、技术标识和非中文同目标有专项反例。此检查沿既有 broker 和免费池路径使用，旧缓存经现有读取校验自然失效，不清理整个缓存。

回归夹具保存专用 Android Firefox 的既有文档中观察到的两组原文与结果。文档最初加载来源、实际胜出供应商及缓存来源未知；离线 mock HTTP 和 broker 端口只能证明共享方向及接受规则，不证明设备持久层、供应商质量或真实请求来源。本次没有参考仓库代码或新增服务、权限、依赖。

限定离线验证已通过：五个直接相关测试文件共 815 项通过，其中中英 adapter 97 项、共享响应与 broker 回归 153 项；两个修改模块的 statements、branches、functions、lines 均为 100%。类型检查、测试归类审计通过；Chrome、Firefox、Safari Web、userscript 生产构建及对应产物校验通过。先前缺少本地 WXT 类型的收集失败及首次覆盖范围不足记录保留，没有降低门槛或清空缓存。构建不代表真实供应商或设备复验，本补丁的这两项验证尚未完成。
