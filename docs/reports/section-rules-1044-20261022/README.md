# 记住局部翻译区域：Issue #1044

[需求](https://github.com/FluentRead/FluentRead/issues/1044)：在相同网站或路径下，重复使用选过的局部翻译区域。

锁定区域后可勾选“记住此区域”，默认在当前目录下提醒，显式确认保存后才执行翻译。保存失败保留选区；未勾选不建立规则。设置页集中管理网站、路径、CSS 定位、模式、启停和翻译方案。方案缺失时保留关联并提示重新选择，用户可以明确改为跟随默认。

确认条突出选区状态与确认动作，范围调整使用有名称的图标按钮，不再读取和重复展示正文摘录或常驻快捷键教程。记忆选项只在勾选后显示，完整作用域供辅助技术及悬停查询；当前目录与整个网站相同时合并重复选择。规则列表只展示网站、启停、下次动作与编辑/删除；CSS 路径在编辑的高级设置中，正常提醒只有一个翻译入口和关闭，失败或方案不可用时才显示必要提示。

## 实现与性能边界

- 规则复用现有配置持久化、字段冲突检查、配置历史和备份；旧备份缺少该字段时保留本机规则。保存内容不含正文、查询参数或翻译凭据。
- 优先稳定锚点，按开放 Shadow DOM 分层定位。每层必须唯一命中；缺失、歧义及受保护区域保留原文，不猜测相似区域。
- 无匹配规则时不创建 DOM 观察器或调度计时器；匹配后合并 180ms 内的变化，规则检查按 8ms 时间片让出事件循环。区域外计数文字与扩展工件变化不重新定位，无轮询。
- 自动执行复用共享队列与有界并发，只补齐未译内容，保留已有译文、在途和失败状态。失败由用户重试；不自动形成服务错误重试循环。
- 手动选区、全文开始或恢复原文后暂停本页自动规则，下一次路由再匹配。路由、隐藏、规则变化和卸载取消旧任务；隐藏后恢复可见重新建立观察。
- 上限为 100 条规则，每条 16 个区域、每条路径 8 层 Shadow DOM，单层选择器 512 字符。拒绝根页面、无界通配和昂贵关系伪类。
