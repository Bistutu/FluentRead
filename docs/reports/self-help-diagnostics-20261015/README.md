基础提交：`fa431a845`。本次只接入 popup、全文状态和服务设置修复路径；没有重做已有语言选择、供应商选择算法或平台适配，也没有借用参考项目代码。生产逻辑与测试均在独立任务 worktree 中完成，未修改主检出。

## 最终行为

- 首次用户保留已有语言选择；主操作旁只显示当前需要的简短提示。只有真实 `translated` 状态才提示译文就绪。
- 内容识别、凭据、模型、限流、超时、离线、页面接入与配置保存失败使用统一安全分类。修复入口定位当前服务，返回时复验原标签页；用户明确重试才恢复并重新翻译。
- 报告默认不存在。用户预览时才创建白名单数据，明确导出后才下载；没有自动上传、剪贴板写入或持久化原始异常。
- 同 URL 刷新使用新文档令牌重新握手，拒绝旧文档广播和迟到回执。权威计数同步不会清掉正在查看的错误与报告。
- 设置页停止检测会停止 UI 等待和后续逐 Key 检测、忽略迟到结果；已经发到后台的当前连通性请求仍可自然结束，本次未新增后台中止协议。

## 精确限制与集成边界

本次没有实际 Firefox/Safari 运行时、移动真机、物理触控板、屏幕阅读器或供应商跨地域/长期稳定性验收。启动 UI 专项注入的是模块加载迟缓/失败；配置存储延迟/失败由生命周期测试覆盖，未注入真实浏览器存储故障。共享诊断、报告操作、首次提示、启动反馈和服务返回路径均支持现有七语言，未知语言回退英文。不能将当前证据表述为全平台或全部在线供应商验收。

共享冲突面为 `PopupApp.vue`、`pageActions.ts`、全文 `runtime.ts`/`stateNotification.ts`、内容查询/菜单回执、`ServiceConfiguration.vue`、后台 `connectionTest.ts` 及测试归属清单。新增 `diagnostic` 与 `documentToken` 是既有消息的附加字段；使用既有配置保存与消息边界。诊断模块不读取配置、浏览器或正文，其他 feature 可通过相同白名单契约接入。
