# 手机语言选择器自适应修复（2026-10-18）

本页记录 `1bae0a2a5` 的修复验收；整合后续主分支后的当前版本见[主分支集成复验](./main9d6-integration-followup.md)。

触屏 Popup 的源语言和目标语言仍沿用桌面 32–35px 控件和 13px 输入，软键盘缩小可见区域后，语言列表也没有对应的高度约束。本次为这两个选择器补齐触屏布局：控件、选项和关闭入口至少 46px，搜索字号 16px；列表根据实际 VisualViewport 收缩，内部滚动，极矮视口优先保留完整关闭入口。桌面继续使用紧凑选择器。

视口订阅只在所属语言菜单打开时存在，关闭、禁用、缓存停用、页面离开和卸载时释放；旧上下文的选择、关闭或浮层回调不能操作新菜单。继续复用真实 UiSelect／Element Plus、既有语言缓存和配置持久化接口。
