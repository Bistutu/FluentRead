# 手机字幕菜单自适应修复（2026-10-18）

用户截图中的菜单受矮播放器裁切，主要操作难以触达。本轮将手机菜单改为按可见视口排布的底部面板，关闭按钮固定，正文独立滚动；不能用此前“可滚动和关闭”的原生结果代替布局验收。

显示方式优先呈现，窄屏分两行，每个触摸按钮至少 44px。普通菜单的校时和下载随后呈现，完整句学习作为次要操作。X 保持观看／字幕选项两层布局。模型、导出子页保留公共关闭和各自取消；隐藏的返回按钮不再参与键盘导航。重新打开回到主要操作，旋转或布局切换保留原菜单节点。桌面继续使用播放器内菜单。

菜单宿主跟随安全视口或实际 DOM 全屏根节点，避开矮播放器裁切，并校正根节点变换。关闭、移除播放器与卸载时释放所属宿主和监听器；未修改供应商、字幕来源或系统 AVKit 能力。

首轮浏览器虽然退出 0，独审发现短视口重开后的校时“＋”按钮右侧两点未命中。增加正文滚动条留白后，第二轮六个主要控件的五点命中全部通过。首轮失败记录保留。

子页首轮还有一处测试误报：裁剪算法把 331.046875px 高的区域当成 331px，误判按钮底部超出 0.046875px。新一轮实际祖先矩形、边框、滚动条和五点命中记录确认完整可见；修正了测量，44px 和可见性阈值保持。该失败也保留。
