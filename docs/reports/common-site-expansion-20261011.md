# 常见站点翻译范围与长页回归（2026-10-11）

在 Product Hunt、Hacker News 的既有修复上，新增五条内置规则，覆盖七种明确的页面形态。规则只将可读标题、摘要和正文交给翻译；名称、作者、来源、时间、计数、操作、编辑器与代码保留原样。目录现在包含 197 条网站规则，历史验证统计保留原日期，本轮范围单独记录。

| 规则 | 本轮范围 | 主要保护边界 |
| --- | --- | --- |
| Bing Search | `/search` 的自然搜索结果标题与摘要 | 来源、日期、广告、答案、侧栏、搜索及分页控件 |
| Steam Community | 应用讨论列表、帖子标题、主帖与回复正文 | 置顶标签、作者、引用作者、时间、计数、编辑器、代码 |
| Google News | `/home` 的可见 `./read/` 新闻标题 | 空隐藏覆盖链接、媒体名称、时间、菜单、导航及侧栏 |
| GitHub Gist | Gist 范围内 Markdown 与评论，包括直属文字、列表及正文表格 | 文件栏、代码行、行号、用户提及、作者与评论操作 |
| Firefox Add-ons | 附加组件摘要、说明、开发者说明与评论正文 | 附加组件名、作者、安装按钮、徽章、评分、展开及评论操作 |

Firefox Add-ons 的摘要位于正文卡片的 header 内，不能套用会排除所有 header 的通用消息模板；此规则使用独立、明确的保护集合。Google News 采用链接语义识别标题，不依赖随机生成的样式类，范围限于首页。Steam 引用中的作者有单独边界，引用正文仍可翻译。

## 局部发现与来源保护

上述正文保持 `resolve: self` 和非原子目标。此前局部修改落在链接或强调标签时，可能找不到它所属的显式正文；简单地将每个子节点重定向到最近正文又会产生重复整段来源。

引擎现在只在外部增量扫描入口，经完整保护检查后，将普通内联脏根提升到最近的显式、自有、非原子正文。遇到原子、跳过、重定向、保护和 ShadowRoot 边界即停止；正文子 frame 仍保持自己的拥有者。内部悬浮子树屏障探测不执行这种提升，避免密集链接段落反复扫描整段。入口规则决策仅在首次同步 enter 前复用，不跨生成器让出保留状态。

## 可重复验证

夹具的文字、身份、代码哨兵和简化布局均独立编写。公开页面 DOM 或所属组件源码只用于确认结构边界。生产扩展加载在隔离临时 Edge profile 中，使用第二屏正常窗口、后台启动和焦点保护；所有翻译响应来自本地固定供应商。

站点 mock 验证真实指针和快捷键、悬浮与全文的翻译—恢复—再翻译、邻段独立性、保护区精确 HTML、请求来源、动态新增、原始 Text 槽更新、元数据噪声和宿主重建。Gist 还验证同 ID 规则替换时的未完成请求：取消后释放旧响应，不得重新写入已保护正文。配置持久化回执早于内容页消费，测试在规则变更前订阅既有 `fluentread-translation-ended` 事件，等待内容页完成同步失效与规则发布后才重启；不靠固定睡眠或重复热键掩盖时序。噪声场景要求新增供应商工作为零，并保留相同译文节点和 HTML。

Steam 与 Google News 的空覆盖链接保留在原创 mock 中。指针定位同时审计真实文字 Range、原生命中栈、同卡关系及透明样式，不移除覆盖层。Google News 的定位样本采用公开首页中标题直属卡片的形态；标题嵌套更深的其他卡片没有本轮几何验收声明。Steam 另对照翻译前后的可读区域、作者溢出及相邻卡片，要求不恶化原布局。

## 长页渲染与证据边界

长页只为新建的普通块级自有双语译文尝试原生 `content-visibility: auto` 和测量高度占位。原文容器、仅译文模式、公式、图片、特殊排版或有装饰、溢出的块保守回退；尺寸校验不通过也立即撤回。外观变化、重挂与恢复清理旧隔离，打印媒体回到普通绘制。不新增全局宿主样式、扫描观察器或计时器。

长讨论、文章和 HTML 论文的 mock 还检查屏外跳过事件、原文恢复、重新翻译、查找、选区、链接焦点与 Tab、浏览器 AX 树、打印媒体及稳定后的布局。原生跳过事件可以证明浏览器采用了屏外渲染能力；同 DOM 计时对照没有建立稳定端到端提速，不能据此宣称零卡顿或 Windows 桌面问题已经解决。

本轮不等同于所有实站布局或翻译服务质量验收。Google News 仅覆盖首页标题；Firefox Add-ons 的结构依据组件源码，匿名页面请求遇到客户端挑战。长页论文样本是 HTML；未验收 PDF、系统读屏、实体打印、低端设备及 Firefox/userscript 运行时。
