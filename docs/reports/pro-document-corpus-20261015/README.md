## 实现结果

- 修复旋转原生文字、双栏顺序、碎表线、合并单元格、无正文横线的数值表、脚注和列表识别。保留原文块与图表中的可搜索字形。
- 长译文可通过键盘打开完整对照；高置信跨页段落可查看上下文。桌面将主要宽度给译文，窄屏按顺序排列，源段落和校订身份保持独立。
- 原版导出增加 Unicode 搜索层；放不下的完整译文在对应原页之后生成可见续页，带源页标签及返回链接。离线或缺字时共用有界 Canvas 回退，纯图页保留。
- 校订恢复优先使用原生位置和精确原文。重复原文不按出现次序猜测；无法确认的校订保留在旧校订区。DOCX/EPUB 展示标签不再干扰原生身份。
- 提供本地材料引用最小公共接口，沿用已有历史和 PR #993 的导入/OCR/导出工作流；没有新增学习中心或并行数据库。

## 远端质量检查发现与修复

首轮 CI 的 288 个受影响测试文件中，284 文件通过，4 文件因五语 userscript 资源摘要漂移失败；共 11229 项通过、8 项失败、5 项条件跳过。独立读取实际基线字典后确认，漂移仅来自本次新增或修改的 7 个文档键。按照现有“已发布远端文档键保持原内容”的契约，构建期静态读取五份已发布 JSON 的 `document.*` 子集，其它词条和扩展词典保持当前内容；固定提交、加载器、生成器与严格摘要门禁均未改动。315 项定向测试、userscript 构建和 verifier 通过，独立复算的五份 JSON 与固定提交文件逐字一致。首轮失败和修复证据保存在 `final-validation/userscript-ci-fix/`，不会将首轮 CI 标记为成功。

另按 CI 条件清空全部可选语料入口，发现物理旋转文字恢复分支此前仅由实际 NASA PDF 覆盖。已补 5 个本地生成的真实 PDF 用例：90/180/270 度物理文字与页面旋转组合的完整恢复，以及无字形或仅少量字形恢复时保持原坐标。相同 9 文件在无语料环境下 312 项通过、3 条件跳过，binary/pdfBlockFit 四维恢复 100%；生产源码与阈值未变。初轮缺口和最终结果分别保存在 `final-validation/ci-no-corpus/` 与其 `final/` 子目录。
