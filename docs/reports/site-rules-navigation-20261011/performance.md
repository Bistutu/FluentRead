# 网站规则性能复验（2026-10-11）

本轮在已修复连续导航的版本上优化“始终翻译此网站”和“在此网站禁用扩展”。比较基线是 `824d9c0c429b7a5143988a7466a0b2cb3b834b43`，不是仍有漏触发问题的旧版本。生产核心源码固定到 `b3322d33423cb1445c221d57fee82741911bbde4`；后续证据、文档和截图调整不改变生产实现。之前的缺陷复现与交互改动见 [原始验证](./verification.md)。未使用参考项目代码。

## 实现与成本

内容页持有两个网站名单的 `Set` 索引。路由查询不再反复归一化整份名单，禁用和自动翻译复用同一次当前地址的基础域解析。同值的新数组保留索引；名单原地修改、添加、删除、留空位后填回都会更新索引。只缓存最近一个地址的基础域，缓存不随浏览历史增长。域名规则仍沿用现有 tldts 解析、private suffix、IDN、IP 和非法网址边界。

配置通知仍逐项比较名单内容，成本是 O(N)，真实修改会重建变化的那个名单。首次构造会提前解析两份名单，即便全局自动翻译已打开或扩展暂时关闭；默认空名单不做域名解析。查询变快的同时，初始化和真实编辑承担索引成本，不能将这项优化描述为所有场景都更快。

生命周期协调改为共享一个在途任务。同一轮同步通知只处理一次；挂载等待期间再收到通知，完成后再读取一次最新状态。关闭扩展仍同步释放功能和在途翻译，路由取消也继续立即执行。挂载失效重试上限保持两次，批次异常后允许后续独立请求恢复。

Popup 网站规则保存移除调用方多余的一次完整 `normalizeConfig`，由原有配置存储完成同步快照、归一化、差量提交和确认。仍捕获同一轮其他设置草稿，不减少持久化校验、不绕过后台确认。测试使用实际 store 验证标量及嵌套草稿、保存后立即修改旧嵌套引用、在途新编辑和旧确认不覆盖新值。没有把配置预处理微测当作点击到保存完成的延迟。

## 工作量与测量边界

纯 Node 对照覆盖 0 / 10 / 100 / 1,000 条每名单、命中位置、未命中、重复地址、锚点、原地修改、同值通知、全局标志和混合路线。计时使用未包装的模块；另编译包装模块统计 `getDomain` / `parse` 次数，包装仍调用同一真实 tldts，不替换域名语义。轮次交替运行新旧实现，保留全部样本；低于 0.2ms 的批次不计算速度比例。受控查询每次评估禁用与自动翻译两个判断，不代表精确浏览器事件轨迹。

两个名单各 1,000 条时，索引预热后的 10 次未命中或新锚点地址查询，域名解析从 30,030 次变为 10 次；10 次完全相同地址查询从 30,030 次变为 0 次。同值及仅标志变化的更新不重新解析名单；修改一份名单的一项仍解析该名单的 1,000 项。这些是确定的模块工作量，不包含浏览器 DOM、渲染、翻译服务和网络耗时。

生命周期对照直接加载新旧模块，以注入的挂载器和规则判断统计调用：

| 场景 | 旧版本 | 新版本 |
| --- | --- | --- |
| 同一轮 100 次通知：挂载器调用 | 100 | 1 |
| 同一轮 100 次通知：bridge 同步 / 映射 DOM 事件 | 200 / 400 | 2 / 4 |
| 挂载在途再来 100 次通知：挂载器调用 | 101 | 2 |
| 挂载在途再来 100 次通知：bridge 同步 / 映射 DOM 事件 | 202 / 404 | 4 / 8 |
| 两种场景：实际启动挂载 / 自动翻译 | 均为 1 / 1 | 均为 1 / 1 |

调用数来自确定性 fixture；DOM 事件数按 composition root 每次 bridge 同步发送两个事件映射，不是浏览器时间采样。禁用同步、完成微任务窗口内重新启用、失败恢复和两次重试上限另有测试断言。

## 定向验证

本轮涉及 9 个测试文件，1,478 个不同用例通过；覆盖率复跑不重复计数。包括网站规则 25、内容 composition root 46、生命周期 19、Popup 37、全文可见性调度 339、Popup 操作归属 57、userscript 构建配置 32、源码文件头 910、模块边界 13。网站规则与页面可用性模块的 statements / branches / functions / lines 均为 100%。测试分类审计通过，651 个文件、10,860 个用例仅做分类，不是全量测试通过声明。

Chrome、Firefox 和 userscript 均构建成功。Firefox / userscript 仅验证构建与相应产物边界，未做真实运行时验收。类型检查仍只有主线已有的 `MangaModelSettings.vue(35,7): TS6133 props is declared but its value is never read`，本轮没有新增诊断；基线独立归档与逐字节一致性见原始验证。

真实浏览器使用隔离 Edge profile、第二屏可见后台正常窗口及焦点监控。翻译来自本地确定性 HTTP 服务；Popup 为扩展测试页，只控制 active-tab 查询以绑定内容页。因此不代表原生工具栏 Popup、在线翻译质量、外部服务性能、Firefox、userscript、BFCache 或任意网站验收。Product Hunt 首页既有 React #418 警告在此前的旧版本对照中也出现，仍作为已知兼容性问题保留。
