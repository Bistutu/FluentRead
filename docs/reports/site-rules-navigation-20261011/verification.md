# 网站规则与连续导航验证（2026-10-11）

本文保留连续导航与交互修复阶段的证据；随后网站规则索引、生命周期通知合并及 Popup 保存优化的最终源码、成本与验证见 [性能复验](./performance.md)。以下构建和覆盖率数据属于原始阶段。

旧生产构建中已复现同类漏触发：开启网站始终翻译后恢复原文，再点击真实 SPA 链接，下一页没有译文，也没有新增翻译请求。路由切换未重新检查自动翻译意图；Product Hunt 首页进入产品页面时，正文适配变化还会结束原翻译会话。修复后按新页面身份重新检查规则，普通页内锚点继续保留当前请求与用户的恢复原文选择。

路由变化会清理旧请求取消域、重试熔断、发现迭代器及扫描冷却，只把文档根登记到现有分片发现队列。它没有在路由事件中增加同步全 DOM 或 ShadowRoot 遍历。自动翻译在页面功能控制器就绪后启动，不再等待其他界面组件完成挂载。这些是实现与定向调度测试证据，不代表外部翻译服务的延迟测量。

Popup 保存网站规则前复验当前标签页，后台确认保存后才显示成功；沿用已有配置存储、差量提交及关闭前交接机制。禁用可中断在途翻译，保留始终翻译偏好，并明确显示暂停状态。保存状态复用现有指示点，范围和优先级通过悬停及无障碍说明呈现，补齐六种界面语言。未使用参考项目代码。
