# 测试执行效率第二轮优化

2026-10-14，以第一轮提交 `45e17986bcc5753275d07f4a1eb1d7134d5d558a` 为固定基线。本轮只修改测试夹具、编译 helper 与验收记录，保留生产源码、测试入口、分组矩阵、文件隔离和四项 100% 覆盖率门槛。

## 实现与保留性

- Options 客户端测试按需创建服务器，省去未使用的 Options SSR 预编译；加载真实依赖的 Vite 服务仍逐例创建和关闭。按完整源码和浏览器缓存纯编译代码。
- Popup 缓存两个组件的编译代码，保留原有 Transition 改写、编译选项和每次模板诊断断言；每例继续执行新模块，创建独立组件、DOM、配置和端口。
- 服务目录、提示词设置与阅读面板复用编译 helper 的不可变脚本源码和渲染代码，保留逐例 Vite 模块加载与模板诊断断言。阅读面板明确保留 Vue 原来的 `cacheHandlers: true` 默认行为。
- PDF 两项字形比较用例将字体解析次数从 18 次减少到 4 次。每个用例仍分别创建普通字符与变体字符解析器，避免 fontkit 按 glyph ID 缓存首次 `codePoints` 时污染字符身份；真实 PDF 导出、子集、复制、取消及全部字形断言保持执行。

静态独立审查确认原有测试定义、名称和参数矩阵保持一致；编译诊断引用与字形查询的等价改写逐项核对，未移除原行为断言。helper 在原有五个契约用例中增加八项不可变性与源码失效断言。九份实际组件编译产物与原实现逐字一致；临时 SFC 探针验证源码修改会立即失效、缓存容量有界，且缓存不包含已执行模块、组件、DOM 或 mock 状态。

## 复验方式

基线从上述固定提交创建独立检出；优化版使用本分支。保持相同依赖和有效 `.wxt` 配置，两者顺序执行。设置 `FLUENTREAD_TEST_MAX_WORKERS=1`、`FLUENTREAD_TEST_CONCURRENCY=1`，提供第一轮记录的真实论文文件：`FLUENTREAD_ATTENTION_PDF` 指向 Attention PDF，`FLUENTREAD_PDF_CORPUS` 指向包含两份原始论文的非空目录。完整对照命令为 `pnpm test:coverage --reporter=default --reporter=json --outputFile=<独立报告路径>`。

专项命令为 `pnpm run test tests/optionsAppNavigationLifecycle.test.ts tests/popupAppLifecycle.test.ts tests/pdfTextExport.test.ts tests/serviceDirectoryLifecycle.test.ts tests/promptSyncLifecycle.test.ts tests/readingPanelLifecycle.test.ts tests/compiledVueFixture.test.ts --reporter=default --reporter=json --outputFile=<独立报告路径>`。使用 `pnpm run test` 转发 reporter 参数；省略真实论文输入会跳过外部语料用例，不能用于零跳过的完整验收。

此验收覆盖确定性测试和覆盖率，未执行产品发布构建、真实浏览器或线上翻译服务矩阵。共享主机负载不能完全控制；三轮专项结果用于观察重复性，单轮完整对照应视为本轮观测值。
