# 视频完整句学习（2026-10-11）

FluentRead 的 YouTube/X 字幕菜单新增可关闭的「完整句学习」。它把原字幕时间轴聚合成学习材料，支持原句重播、单句循环、句末暂停、按需解释、确认译文后收藏，以及学习中心回到带时间点的出处。默认视频观看流程无需进入学习。界面以双语阅读卡呈现，重播与收藏有清楚主次；编辑按需打开，播放辅助采用互斥选项，头尾固定、正文滚动，面板可以收起。

## 实现与边界

- 原句：复用已有原始 cue。仅在 cue 边界识别句末标点；无标点材料受 20 秒、420 字符、24 cue、1.5 秒间隔限制。单个 cue 内多句保留整个原始区间，不估算内部时间。没有原时间轴时显示空态；YouTube 机器译轨不能当作原句；X 正在生成的 AI 时间轴须等完整生成。
- 译文与解释：整句原文经现有翻译客户端请求，不使用人工译轨中点配对伪装整句翻译。源语言来自原始轨元数据，X 无语言轨的 `original` 占位符回退到视频源语言配置。用户编辑不会被迟到结果覆盖；编辑固定当前句，切句保留本次会话草稿。停止讲解可编辑已返回内容，空译文不保存，清空讲解后更新收藏会实际清除旧内容。解释仅主动点击后沿用现有 AI 讲解及语境范围，相邻文字各最多 800 字符。
- 播放：控制器绑定原媒体元素，不改倍速或创建播放器。换句只 seek，不自动播放；重播明确调用 play。手动拖动解除控制，用户暂停不会被恢复；关闭、换视频、播放器重建、关闭字幕、配置变化及卸载清理请求和控制。
- 收藏：显式 upsert 到现有词书，保存原句、当前译文、解释、前后语境、标题、可靠来源和原始起止时间。毫秒持久化向外取整不足 1ms，播放仍使用原值。同句按已有语言身份合并，片段身份参与语境去重；正常语境限 500 字符，视频语境限 6000。
- 回出处：YouTube 使用规范化视频 ID 与时间参数。X 使用 FluentRead fragment，并要求当前视频可靠来源与目标完整相同；编号视频只有局部 `video/N` 链接能证明身份时才定位，只有一个 DOM video 也不能凭页面编号或旁边链接猜身份，引用帖与主帖歧义不猜地址。来源不可靠时保留标题、文本和时间并提供恢复提示。删除、登录限制或失效页面不保证可返回。
- 隐私：视频语境沿用私密上下文选项，默认安全导出不含地址、标题、语境与片段时间；主动私密 JSON/Anki 导出可保留回出处信息。无新增录音、后台采集或自动收藏。

代码分别由 `sentenceTimeline.ts`、`sentencePlayback.ts`、`sentenceLearningHost.ts`、`VideoSentenceLearning.vue` 与 `vocabulary/source.ts` 承担聚合、媒体控制、挂载及可靠来源、交互、来源持久化。少量既有渐进 cue 选择和字幕 DOM 清理迁回 `subtitleLogic.ts` / `ui.ts`，运行时保持在原有 1887 行上限内。面板经 WXT 0.20.18 既有 style 节点显式注入；未依赖 Shadow UI 自动 CSS。没有修改或借用参考仓库代码，没有升级依赖或新增权限。
