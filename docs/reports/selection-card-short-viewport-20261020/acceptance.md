# 划词卡片在极矮可见视口下的滚动修复

旧卡片在 58px 的安全可见区域中仍保留上下各 12px 间距，实际外框仅 34px，44px 关闭按钮下缘被裁切；该位置的点击落到了宿主页面。专项单测与旧生产包均复现了问题。

修复后，空间不足时同一卡片使用整卡滚动并收紧顶栏间距。触摸滑动不再被标题拖动捕获；内容、输入、请求和语音归属保持，视口恢复后沿用原有手动位置与尺寸。普通桌面继续使用原有紧凑卡片。
