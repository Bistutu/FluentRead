# 个人校订交付核对

任务分支为 `codex/personal-corrections-20261011`。本轮整合 main 提交 `1983644dfb7537290573231b0db283877c03e410`，保留个人校订元数据和 main 的 AI 上下文节点传递；测试分类、覆盖率入口及测试指南保留双方内容。英文指南同步默认关闭、当前网页范围、轻量来源文字及悬停提示。

下表按原始网页闭环和后续产品修正核对。浏览器编号对应 [browser-report.json](./browser-report.json) 中 `cases` 的顺序；源码和实际断言共同支持结论，浏览器使用生产 Chrome MV3 扩展在隔离 Edge 中运行。

| 要求 | 实现及验证证据 |
| --- | --- |
| 主动开启后才使用；默认关闭 | 配置仅接受布尔 `true`，总开关同样门控；浏览器 #1、#2 验证默认零消息、无入口及真实设置持久化，#4、#6 验证关闭恢复、记录保留和再开启 |
| 原文—译文对可编辑；先预览再确认保存 | controller 校验有效草稿、当前来源、范围和预览状态；控制器测试确认未预览时保存零调用，浏览器 #3 验证实际编辑、预览和保存 |
| 明确的当前网页与轻量项目范围 | 完整网页地址的摘要区分查询及片段；创建项目不自动加入，预览前检查显式关系；领域/控制器断言与浏览器 #10、#13 验证隔离、加入、复用及退出 |
| 精确原句、源/目标语言和语境隔离 | matching 严格比较原句及原文标题，`auto` 与明确源语言分开；领域测试改变大小写、空白、数字、语言、标题和材料均不命中；浏览器 #14、#15、#19 |
| 近似句只提供差异和草稿；冲突不自动覆盖 | 候选显示保存/当前原句，选作草稿后仍需预览；不同已确认译法返回 conflicts；请求测试证明仍走普通服务，浏览器 #7、#17 |
| 管理编辑、删除、变更失效和安全撤销 | expectedRevision 与 successor 版本检查避免覆盖后续变更；领域测试验证删除/撤销和版本竞争，浏览器 #8、#9、#11 验证可见旧译文失效 |

| 关闭、取消、迟到响应、重复触发及 DOM/路由变化 | 启用代次、取消信号、材料、标题、来源和节点所有权共同复验；DOM/runtime 测试覆盖旧查询与旧刷新，浏览器 #12、#15、#16、#18 验证单一编辑器、标题/SPA 失效及关闭 |
| 本机存储且不污染公共缓存、词表、历史、云同步或备份 | 独立加密仓库和显式确认保存；领域测试实际检查配置导出、历史、自动备份及云投影无个人正文/记录 ID/仓库键；浏览器公共缓存抽查 `containsPersonalText=false` |
| 不自动收集阅读历史，不保存密钥或请求头 | 保存模型仅含用户确认的原译文、语言、语境、显式范围及版本；网页地址只作摘要身份；没有自动记录阅读事件的写入路径 |
| FluentRead 风格、易懂范围和简洁提示 | 来源无独立描边/底色；语言名称位于页签栏最右侧且不改变匹配代码，紧凑范围位于底部；默认“仅当前网页”；帮助 hover/Tab 显示、Escape 分层收起、保存反馈“已保存”；实际 Vue 测试和浏览器 `compactLayouts`/`helpInteractions` 验证布局、提示与固定底部锚点。最新390px预览的 scrollHeight/clientHeight 均为659，`narrowHelpScroll.tested=false`，本轮未执行滚轮检查；Vue 测试另覆盖提示的滚动监听与视口定位 |
| 项目输入按需展开且不遮挡主要操作 | 输入弹层锚到整个底部操作栏，成功创建后收起，失败保留输入；异步完成复验关闭、管理、当前节点和卸载状态；真实浏览器验证有撤销按钮时的390px展开、输入与创建，新项目不自动加入 |
| 安全网页单元边界 | 仅接入可安全拍平的网页双语文本；受保护代码/公式、仅译文、PDF、字幕及 userscript 不启用此编辑流程；请求测试与 userscript 构建/能力 verifier |
| 小范围接入现有架构 | core 纯模型、services 持久化协议、既有 background 路由及 content composition；沿用 WXT/Vue/TypeScript，未改请求调度或复习算法，未引入参考仓库依赖 |

| 可审阅实现与验证材料 | 当前任务分支、[功能报告](./README.md)、[使用指南](../../guide/webpage-translation.md)、[英文指南](../../en/guide/webpage-translation.md)、归档测试/覆盖率/浏览器 JSON 与真实截图 |
