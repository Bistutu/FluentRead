# 网页个人校订与范围复用

本次实现让读者主动开启个人校订后，在网页双语译文上编辑、预览并确认保存，在当前网页或明确加入的一组相关网页中复用相同原句。功能默认关闭；编辑、删除和撤销走独立版本化记录，普通供应商结果与个人译法保持各自来源。

## 行为与边界

- 在“设置 → 翻译设置 → 阅读辅助”主动开启“个人校订”后，悬停已译双语段落使用“校订译文”或 `Alt/Option+Shift+E` 打开编辑器。必须填写译文、选择使用范围并预览受影响的当前单元后确认保存；只有确认动作持久化原句与译文。
- 默认关闭时不挂载编辑入口、不查询校订记录、不改变普通服务翻译。旧配置或无效值也默认关闭，只有显式布尔 `true` 开启；插件总开关同样门控。开启后可直接编辑已有服务译文，不自动重译或替换整页。
- 关闭时立即收起编辑器、取消订阅并恢复当前个人译文：有服务底稿回到底稿，无底稿回到原文。记录继续保留；再次开启后在后续翻译时复用。关闭期间的迟到查询、刷新或旧启用代次不能采用个人结果；普通服务结果仍可正常提交并按新代次编辑。
- 使用范围的默认文案为“仅当前网页”；多网页范围称为“一组相关网页”，由读者创建并通过独立动作加入。内部材料身份是完整 URL（含 query 和 fragment、去掉 userinfo）的 SHA-256，不保存原始地址。没有隐式跨站通用规则。
- 源/目标语言以易读名称放在页签栏最右侧，与“已保存的校订”保持间距，不单占正文一行；原语言代码仍用于匹配，完整名称和代码保留在提示中。范围选择以 128×30px 控件放在底部操作栏，旁边保留帮助与“新建项目”入口，长项目名称不撑开布局。
- 范围、项目和相同原句复用规则收在底部信息图标内，鼠标悬停或键盘聚焦时显示，Escape 只收起提示。项目输入按需展开并锚到整个操作栏，避免有撤销按钮时的窄屏裁切；成功创建后收起并聚焦范围选择，失败保留输入和错误，不自动加入项目。普通保存反馈为“已保存”；冲突和错误仍直接呈现。提示留在同一隔离 Shadow Root 内，避免面板滚动区域裁切。
- 自动复用要求原句、源语言、目标语言、最近原文标题语境及可用范围全部匹配。源语言 `auto` 与明确的语言分别匹配。该语境标识不能证明语义等价；对于指代等需要人工确认的内容，读者仍应检查译文。
- 近似候选显示记忆原句与当前原句，采用候选只填入草稿。存在不同的已确认译法时不自动复用，提示在管理中审阅并解决冲突。
- 可见个人结果带轻量“个人校订”来源文字，沿用译文颜色并降低字号与不透明度；没有独立边框或标签底色，不进入复制内容。编辑器沿用 FluentRead 的中性底面、主题强调色、轻操作页签及字号留白。删除、撤销或退出项目后，有服务底稿的当前单元回到服务译文；没有底稿的复用单元恢复原文。标题或 SPA 材料地址改变时，旧语境的个人结果立即恢复原文。对节点归属或来源已改变的单元，交给原有翻译修复流程。
- 记忆为本机加密数据，独立于配置备份、历史、云同步、词表、学习记录及公共 provider 缓存。最多 1,000 条校订、100 个项目、30 条可撤销变更，序列化数据最多 4 MiB；撤销受记录版本约束，不覆盖后续修改。
- 本次入口仅用于安全的网页双语文本单元。保留代码、公式等不可安全拍平的结构；仅译文、PDF、字幕和 userscript 不提供此编辑流程。

## 实现归属

纯领域位于 `src/core/personal-corrections/`；存储与串行版本变更位于 `src/services/personal-corrections/`、`src/platform/storage/personalCorrectionRepository.ts`。后台沿用唯一消息路由，验证扩展发送者、当前材料及显式项目关系，拒绝隐私窗口访问。

Vue 编辑器、可信输入和取消生命周期位于 `src/features/personal-corrections/`。主动开启后，全文功能在 provider 请求前读取精确个人记忆，提交前复验记录版本、语言、材料、标题、来源、节点所有权和启用代次；确认变更通过无正文广播更新可见单元。已有译文在首次指向时按原请求语言准备安全编辑对，不查询记录。标题/结构观察只作无 IO 失效检查，不记阅读历史、不请求翻译。
