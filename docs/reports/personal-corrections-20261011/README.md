# 网页个人校订与范围复用

本次实现让读者在网页双语译文上主动校订、预览并确认保存，在同一材料或明确加入的项目中复用相同原句。编辑、删除和撤销走独立版本化记忆；普通供应商结果与个人译法保持各自来源。

## 行为与边界

- 悬停已译段落后使用“校订译文”或 `Alt+Shift+E` 打开编辑器。必须填写译文、选择范围并预览受影响的当前单元后确认保存；只有确认动作持久化原句与译文。
- 默认范围为当前材料；材料身份是完整 URL（含 query 和 fragment、去掉 userinfo）的 SHA-256，不保存原始地址。项目由读者创建，并通过单独的“加入项目”动作将材料纳入。没有隐式跨站通用规则。
- 自动复用要求原句、源语言、目标语言、最近原文标题语境及可用范围全部匹配。源语言 `auto` 与明确的语言分别匹配。该语境标识不能证明语义等价；对于指代等需要人工确认的内容，读者仍应检查译文。
- 近似候选显示记忆原句与当前原句，采用候选只填入草稿。存在不同的已确认译法时不自动复用，提示在管理中审阅并解决冲突。
- 可见个人结果带“个人校订”来源提示。删除、撤销或退出项目后，有服务底稿的当前单元回到服务译文；没有底稿的复用单元恢复原文。标题或 SPA 材料地址改变时，旧语境的个人结果立即恢复原文。对节点归属或来源已改变的单元，交给原有翻译修复流程。
- 记忆为本机加密数据，独立于配置备份、历史、云同步、词表、学习记录及公共 provider 缓存。最多 1,000 条校订、100 个项目、30 条可撤销变更，序列化数据最多 4 MiB；撤销受记录版本约束，不覆盖后续修改。
- 本次入口仅用于安全的网页双语文本单元。保留代码、公式等不可安全拍平的结构；仅译文、PDF、字幕和 userscript 不提供此编辑流程。

## 实现归属

纯领域位于 `src/core/personal-corrections/`；存储与串行版本变更位于 `src/services/personal-corrections/`、`src/platform/storage/personalCorrectionRepository.ts`。后台沿用唯一消息路由，验证扩展发送者、当前材料及显式项目关系，拒绝隐私窗口访问。

Vue 编辑器、可信输入和取消生命周期位于 `src/features/personal-corrections/`。全文功能在 provider 请求前读取精确个人记忆，提交前复验记录版本、语言、材料、标题、来源与节点所有权；确认变更通过无正文广播更新可见单元。标题/结构观察只作无 IO 失效检查，不记阅读历史、不请求翻译。
