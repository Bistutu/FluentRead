# 油猴构建环境差异与完整许可去重

PR #1009 的旧 CI 在油猴大小检查失败。原始日志表明实际测试的是合成合并 25c8d756（703f 合入较新的 main），并非原分支。对同一精确 git 树重新构建，本地为2,100,791B，CI为2,101,787B，环境差996B。尚无 CI 的逐块输入／压缩产物，因此没有将差异归因到某一 gzip 块或特定 zlib。

构建期的全部11个 gzip 入口统一使用锁定 pako 2.1.0、level9，覆盖标准与独立版。输入序列化、运行时解压端口、依赖、发布模式和体积上限保持。新增测试使用独立 gzip 解码器、既有二进制／UTF-8 解码器，覆盖全字节、偏移视图、空流、Unicode、NUL、输入保留、重复结果，以及宿主 gzip 不可用时真实站点数据完整还原。

补充构建发现完整独立包原有3,606,108B超限；恢复原始压缩源码的受控基线同样失败，不能算作新 helper 回归。最终仅在独立包许可列表中共享逐字相同的完整许可正文；每个包的包名、版本及许可标题逐个保留。版权或内部空白有差异的正文独立保留，没有按 MIT 名称或许可片段合并。

| 实际最终产物 | 大小 | 原有上限 | 结果 |
| --- | ---: | ---: | --- |
| 标准油猴 | 2,101,071B | 2,101,100B | 通过；两个独立进程构建哈希相同 |
| 完整独立油猴 | 3,598,403B | 3,600,000B | 通过；不需要远程 JavaScript |

11个相关测试文件实际执行906项、全部通过、无跳过；类型检查通过。实际独立产物的28个包标题和20份独特许可全文，已与锁定安装包的 manifest／完整 LICENSE 逐项核对。Root 与独立 Agent 审查了代码及操作边界；原始执行回执、失败基线与最终哈希见[验证记录](./verification.json)。

这些结果尚不证明新提交的远程 CI 通过、所有平台整包字节一致或实际脚本管理器／Safari 运行时验收。移动端与 Safari 长期目标仍未完成，PR不自动合并。本次未借鉴或修改参考项目。
