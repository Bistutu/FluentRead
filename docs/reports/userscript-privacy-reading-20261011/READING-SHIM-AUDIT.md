The enabled reading UI reached `ReadingPanel.run` → `streamReading` → `runtime.connect`, but HEAD `09bc5913ca239eadade50ffbdb7e731bda66d79a` supplied neither a connect shim nor a Harness route in either userscript platform. This is a source-proven missing composition boundary. No browser failure or fix acceptance was executed by this reviewer.

The three delivered patches add actual paired FIFO ports, a userscript composition of the unchanged shared reading handler/stream adapter and real Harness runtime/model gateway/loop, and eight integration cases in the existing client test file. Patch SHA256 values and exact source hashes are in `READING-SHIM-AUDIT.json` and the individual PREIMAGES receipts. Parent has begun integrating them; their observed working tree is not a frozen release tree.

The terminal ordering is essential: shared `streamPort.ts` posts its result and immediately disconnects. Ports must deliver that already queued packet before the disconnect event. Messages are cloned when posted. Only the internal server receives the frozen owner metadata; client payload sender/URL/privacy fields cannot replace it. Existing validation, request IDs, document-scoped cancellation, readiness, replacement, timeout and late-result suppression remain intact.

Reading is explicitly ephemeral in every manager privacy state. The composition omits session, memory and model-usage stores/readers/sinks, emits `session.persistent:false`, and rejects session/anchor restoration and memory CRUD with an honest reason. Actual Harness run supports four local follow-up turn pairs. Parent preserves privacy metadata as true/false/unknown and uses a separate UI persistence capability; no forced incognito flag disables storage. Parent also changed proposed UUID identity to a local owner sequence to support HTTP pages without secure-context UUID.

Handler replacement disposes the old owner. Main cleanup separately stops reading ports/subscriptions while preserving the existing final count flush route. A changed actual page URL is denied at subsequent eligibility checks; this patch does not add a separate immediate SPA navigation listener.
