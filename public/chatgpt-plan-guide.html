ChatGPT 套餐接入尚未开放

FluentRead 当前公开版本尚未开放此服务，所需的 OpenAI 申请与批准尚未完成。

请返回“设置 → 翻译服务”，继续选择当前可用的服务。已有配置和完成的译文保留；若之前保存过 ChatGPT 套餐服务或模型，请先为需要使用的功能选择可用服务，原有配置无需删除。

开放后将提供从扩展发起官方授权并自动返回的完整流程。实际账户资格、模型与用量以 OpenAI 权限为准。

English

ChatGPT plan integration is not available in current public FluentRead releases. The required OpenAI application and approval have not been completed.

Return to Settings → Translation services and choose an available provider. Existing settings and completed translations are retained. If a ChatGPT plan service or model was saved previously, choose an available provider for the features you need; the saved configuration does not need to be deleted.

A future public release will offer official authorization from the extension and an automatic return. Actual account eligibility, models, and usage will depend on OpenAI's permissions.
