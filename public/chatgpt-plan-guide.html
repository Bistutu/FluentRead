使用 ChatGPT 套餐

使用符合资格的 ChatGPT Plus 或 Pro 账户授权，无需 API Key。翻译、阅读讲解和写作会使用你的套餐额度，可用模型及限额由账户决定。

  1. 安装 Node.js 20 或更新版本，取得包含 integrations/chatgpt-plan 的 FluentRead 源码。
  2. 在源码目录打开终端，运行 node integrations/chatgpt-plan/cli.mjs，并保持终端打开。助手只监听本机 127.0.0.1:18743。
  3. 在“翻译服务 → ChatGPT 套餐”输入终端显示的配对码。配对码 5 分钟有效；过期后在终端输入 pair 生成新码。
  4. 点击 Continue with ChatGPT，在官方页面完成登录并允许套餐使用；返回 FluentRead 设置页。
  5. 选择账户返回的模型，再将服务设为默认或用于单独的功能。“检查连接”会发送一次使用套餐额度的最小翻译请求。

重新启动助手后，已有配对和登录仍会保留。不同浏览器或扩展安装需要分别配对。

恢复与账户管理

“管理套餐用量”打开 ChatGPT 用量设置。达到额度后请等待恢复或调整预算。“切换账户”会新建授权注册，新授权失败或取消不会覆盖原连接。

“退出 ChatGPT 账户”清除本机 OAuth 凭据并取消未完成的请求，保留配对和已完成译文。远端撤销未确认时，请在 ChatGPT 设置中检查并移除共享。关闭助手后，启动它即可重新尝试。

凭证保存

OpenAI 令牌保存在助手的私有本机目录，默认 ~/.config/fluentread-chatgpt-plan。扩展只持有独立配对凭证。两者均不进入配置历史、导出或云备份。不要分享终端配对码。

必要的文本和上下文会随模型请求发送给 OpenAI，授权不会读取你的 ChatGPT 历史对话。完整结果以 response.completed 为准，失败或断流不会提交为成功。

OpenAI 官方接入说明 · 套餐协议限制

English setup

Use Node.js 20+ and a FluentRead source version containing integrations/chatgpt-plan. Run node integrations/chatgpt-plan/cli.mjs from that directory and keep the terminal open. In settings → ChatGPT Plan, enter the one-time pairing code, choose Continue with ChatGPT, authorize an eligible Plus or Pro account, and select a model from its current catalog.

OpenAI tokens stay in the helper’s private local directory. Pairing is separate and survives restarts. Neither credential appears in configuration exports or cloud backup. Manage plan usage in ChatGPT settings. Sign out to remove local OAuth credentials; if remote revocation is unconfirmed, remove app access in ChatGPT settings.
