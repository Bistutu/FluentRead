# 渐进阅读

在网页选中一个词、短语或段落，打开 FluentRead 快捷面板并点击「渐进阅读」。也可先开启面板，再选择正文并点击「读取选中的正文」。每个新选文从「只读原文」开始，此选择不修改网页翻译或持久偏好。

四种帮助可以自由切换：

- **只读原文**：保留原网页 DOM，并在面板呈现纯文本原文。
- **短语提示**：匹配现有收藏及少量本地多词表达；对用户选词提供「翻译这个表达」，沿用翻译服务、上下文设置和缓存。机器翻译可能没有语境能力，AI 也遵循既有页面上下文开关；不保证表达译文选中正确义项，可一步查看完整双语。
- **逻辑线索**：引用原文中明确的否定、可能性、条件和范围词。它是有界词面规则，不是完整句法/语义分析；没有匹配不代表没有歧义。
- **完整双语**：任何档位都可以一步直达，无需逐级完成、提交学习反馈或标记掌握。只复用真实已完成且原文完全对应的网页译文，否则使用既有翻译客户端。

短语释义和收藏译文都是参考，未做义项相同推断。仅收藏当前状态为 mastered、最新学习记录确为 manual-mastered 且当前规范化原文完全等于保存语境时自动收起提示；熟悉的新语境、自动复习所得 mastered、缺失/陈旧/冲突日志都不触发退场。「仍需要帮助」可以恢复所有已收起提示。学习中心修改掌握状态后通过已有变更通知刷新；面板不写学习状态。

会话只在主动打开期间持有瞬时选区。未发生模型查询时，原文和规则不会额外调用 AI。关闭、停用、页面离开或扩展失效释放 UI、观察器、监听和待处理请求；网页正文变化后清空旧结果，提示重新选择。原网页文本仍可选择、复制，链接和控件仍归网页所有。表单、编辑区、代码、扩展 UI 和跨段选区不作为正文。

无痕模式不读取学习库。用户脚本和原生 PDF 不提供本入口；本次没有添加权限或改变翻译/校订/复习算法。

针对性验证：`tests/progressiveReading*.test.ts`、`tests/vocabularyReadingHints.test.ts`、Popup ownership/visibility tests；`scripts/run-progressive-reading-test.cjs` 在隔离 Edge 正常窗口通过 CDP 操作生产扩展与本机确定性 HTTP 夹具。浏览器证据只能证明实现和交互，不能证明真人理解率提升或真实供应商翻译质量。
