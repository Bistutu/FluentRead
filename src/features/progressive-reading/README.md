# 渐进阅读

在网页选中一个词、短语或段落，打开 FluentRead 快捷面板并点击局部右侧的「学习」。也可先开启面板，再选择正文并点击「读取选中正文」。每个新选文从「只读原文」开始，此选择不修改网页翻译或持久偏好。

Popup 将翻译、局部和学习以 42px 高度同排。主按钮移除静态“A↔译”和独立快捷键框，保留加载状态，默认合并显示「翻译（⌥+T）」；读取实际配置并按平台缩写，长组合在完整悬停提示中展示。网站规则保留两个独立按钮并去掉共同外层框。仅选择正文或悬停不会自动打开渐进阅读。

学习快捷键默认未设置，旧配置也保持仅点击触发。悬停或聚焦「学习」显示用途、当前快捷键和「设置快捷键」入口，直达 `options.html?target=progressive-reading#settings-translation`。可以录制自定义组合、取消或清除；清除后即时恢复仅点击。设置及运行时检查已启用动作的组合冲突，输入框、编辑区域、扩展控件、组合输入和重复按键不会触发；多次触发只打开一个面板。

[实际操作动图与验证记录](../../../docs/reports/progressive-reading-20261011.md) 展示“打开空面板 → 拖选正文 → 读取选文 → 切换帮助 → 关闭”的流程。录制使用真实生产扩展和本机测试正文，字幕和指针仅用于演示；翻译响应为确定性本机夹具。

朗读工具栏默认不自动播放，复用划词朗读的来源与音色设置。原文可随时朗读，译文需先取得完整双语；切换对象后再点击播放。支持暂停/续播、前后 5 秒、从头重听、0.75× 至 1.5× 语速及本段循环。每个面板只持有一份当前音频，暂停、跳转、调速和重听不重复合成；分词按文本缓存，媒体事件推进估算高亮，不创建进度轮询。换文、关闭、配置语言/语音策略变化及卸载停止请求并释放 Blob。

四种帮助可以自由切换：

- **只读原文**：保留原网页 DOM，并在面板呈现纯文本原文。
- **短语提示**：匹配现有收藏及少量本地多词表达；对用户选词提供「查询表达」，沿用翻译服务、上下文设置和缓存。机器翻译可能没有语境能力，AI 也遵循既有页面上下文开关；不保证表达译文选中正确义项，可一步查看完整双语。
- **逻辑线索**：引用原文中明确的否定、可能性、条件和范围词。它是有界词面规则，不是完整句法/语义分析；没有匹配不代表没有歧义。
- **完整双语**：任何档位都可以一步直达，无需逐级完成、提交学习反馈或标记掌握。只复用真实已完成且原文完全对应的网页译文，否则使用既有翻译客户端。

短语释义和收藏译文都是参考，未做义项相同推断。仅收藏当前状态为 mastered、最新学习记录确为 manual-mastered 且当前规范化原文完全等于保存语境时自动收起提示；熟悉的新语境、自动复习所得 mastered、缺失/陈旧/冲突日志都不触发退场。「仍需要帮助」可以恢复所有已收起提示。学习中心修改掌握状态后通过已有变更通知刷新；面板不写学习状态。

会话只在主动打开期间持有瞬时选区。未发生模型查询时，原文和规则不会额外调用 AI。关闭面板释放 UI、正文观察器和待处理请求；停用、页面离开或扩展失效进一步注销功能监听；网页正文变化后清空旧结果，提示重新选择。原网页文本仍可选择、复制，链接和控件仍归网页所有。表单、编辑区、代码、扩展 UI 和跨段选区不作为正文。

面板沿用 FluentRead 划词卡片的粉色品牌、白色表面与灰色分隔；深色主题使用对应深色卡片，并跟随系统自动主题变化。辅助解释收在可聚焦的提示入口中，保持正文和阅读动作清晰。

无痕模式不读取学习库。用户脚本、原生 PDF 和 Thunderbird 不提供本入口；本次没有添加权限或改变翻译/校订/复习算法。

针对性验证：`tests/progressiveReading*.test.ts`、`tests/vocabularyReadingHints.test.ts`、Popup ownership/visibility tests；`scripts/run-progressive-reading-test.cjs` 在隔离 Edge 正常窗口通过 CDP 操作生产扩展与本机确定性 HTTP 夹具。浏览器证据只能证明实现和交互，不能证明真人理解率提升或真实供应商翻译质量。
